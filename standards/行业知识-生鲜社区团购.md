# 行业知识 — 生鲜社区团购 / 即时零售（电商-生鲜子类）

> **定位**：沉淀"生鲜社区团购/即时零售"行业的产品经理常识。生成该行业项目时，步骤⑤前读取，作为信息架构调研的起点。
>
> **来源**：基于 2024-2026 行业认知 + 天天买菜项目实践沉淀。**待增强**：联网调研竞品最新动态（美团买菜→小象超市、多多买菜、叮咚买菜、朴朴超市、盒马鲜生），用户需要深度竞品分析时显式要求再联网。
> **行业识别**：需求含"买菜/生鲜/社区团购/自提点/次日达/即时配送" → 命中本行业。

---

## 一、行业画像

| 维度 | 内容 |
|:--|:--|
| 目标用户 | 家庭采购决策者（25-45 岁、有孩家庭、双职工）、对价格敏感但重品质、注重时效的社区住户 |
| 核心场景 | ① 下班后到家前的即时买菜（30-60 分钟送达）；② 次日自提的平价团购（提前一晚下单）；③ 周末囤货/家宴食材；④ 应急补货（缺葱姜蒜）；⑤ 老人代买/子女远程下单 |
| 商业模式 | 平台赚取商品差价 + 履约费 + 供应商佣金/账期；团购模式靠"预售集单"降损耗 |
| 关键指标 | GMV、次日/即时履约时效、订单取消率、损耗率、复购率（生鲜核心是复购）、自提点/履约网络密度 |

## 四、信息架构范式（行业主流布局，调研起点）

- 首页结构：搜索框 → 金刚区（品类直达）→ Banner/活动 → 限时秒杀 → 推荐瀑布流（"为你推荐"）。生鲜强调"新鲜+时效"，Banner 常用"XX分钟达/次日达"心智文案
- 导航模式：底部 Tab 典型 5 个——首页 / 分类 / 购物车（带角标）/ 订单 / 我的
- 关键二级页：商品详情（重量+产地+评价）、秒杀活动页（倒计时+商品墙）、自提点选择、订单跟踪页

## 五、易错产品逻辑（该行业高频坑）

| # | 易错点 | 行业原因 | 对策 |
|:--|:--|:--|:--|
| 1 | 商品缺图/图区空白 | 生鲜商品量大，图片素材易缺 | 图区必须渐变占位 + 品类图标，禁止空白（M78） |
| 2 | 倒计时不生效 | 活动/秒杀是生鲜核心，倒计时契约错 = 活动死 | data-countdown 必须绝对时间戳 + 三格结构（M73） |
| 3 | 运费规则混乱 | 满 X 免运费是生鲜常态，规则不一致会劝退 | 结算页运费逻辑与商品总价联动，规则写进契约 |
| 4 | 履约时效无感知 | 生鲜核心是"新鲜+按时"，无时效=无信任 | 商品/详情/订单显式标注送达时段或自提方式 |
| 5 | 自提点/地址选择缺失 | 社区团购/次日达依赖自提点网络 | 自提点列表 + 地图 + 取货码，入口要直达 |
| 6 | 库存/售罄无状态 | 生鲜易售罄，无状态导致下单失败 | 商品售罄置灰 + 到货提醒，禁止点了无反应 |
