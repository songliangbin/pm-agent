# 动效规范 v1.0

> 本规范定义移动端交互原型的所有动效标准，确保原型具备真实App级别的流畅感和品质感。
> 与 `UI质感规范.md` 配合使用，质感解决"静态好看"，动效解决"动态流畅"。

---

## 一、动画基础参数

### 1.1 缓动曲线（Easing）

| 名称 | CSS 值 | 用途 | 感觉 |
|:--|:--|:--|:--|
| 标准出 | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场、展开、悬浮 | 轻快、自然 |
| 标准入 | `cubic-bezier(0.7, 0, 0.84, 0)` | 退场、收起 | 干脆、利落 |
| 弹性 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 点赞、角标、成功提示 | 活泼、有弹性 |
| 线性 | `linear` | 进度条、轮播、旋转 | 匀速、机械 |
| 柔和 | `cubic-bezier(0.4, 0, 0.2, 1)` | 颜色过渡、透明度 | 平滑、低调 |

### 1.2 持续时间基准

| 类型 | 时长 | 说明 |
|:--|:--|:--|
| 微动效 | 150-250ms | 按钮反馈、图标变化、数字跳动 |
| 标准动效 | 300-400ms | 卡片入场、Tab切换、弹窗展开 |
| 入场动画 | 400-600ms | 页面加载、列表渲染、骨架屏过渡 |
| 转场动画 | 300-500ms | 页面跳转、底部面板滑出 |
| 循环动画 | 800ms-2s | 加载旋转、骨架屏shimmer、呼吸灯 |

### 1.3 交错延迟（Stagger）

列表/网格元素依次入场，创造节奏感：

```css
.item:nth-child(1) { animation-delay: 0ms; }
.item:nth-child(2) { animation-delay: 60ms; }
.item:nth-child(3) { animation-delay: 120ms; }
.item:nth-child(4) { animation-delay: 180ms; }
/* 以此类推，每元素间隔 50-80ms */
```

## 二、入场动画

### 2.1 页面入场

页面首次显示时的整体入场效果：

```css
@keyframes pageEnter {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}
.page-enter {
  animation: pageEnter 0.45s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
```

**规则**：
- 位移距离：15-25px（过小无感，过大拖沓）
- 透明度：0 → 1
- 时长：400-500ms
- 缓动：标准出

### 2.2 列表/卡片入场（瀑布流效果）

```css
@keyframes cardEnter {
  from { opacity: 0; transform: translateY(30px) scale(0.96); }
  to   { opacity: 1; transform: translateY(0) scale(1); }
}
.card-enter {
  opacity: 0;
  animation: cardEnter 0.5s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
```

**规则**：
- 初始状态：`opacity: 0`（必须，避免闪烁）
- 位移+微缩放组合，比纯位移更有质感
- 交错间隔：50-80ms
- 最多延迟不超过 600ms（避免用户等待）

### 2.3 骨架屏 → 真实内容过渡

骨架屏消失、真实内容出现的衔接动画：

```css
/* 骨架屏淡出 */
.skeleton-fade-out {
  animation: skeletonFade 0.3s ease forwards;
}
@keyframes skeletonFade {
  to { opacity: 0; }
}

/* 真实内容淡入 */
.content-fade-in {
  opacity: 0;
  animation: contentFade 0.4s cubic-bezier(0.16, 1, 0.3, 1) 0.15s forwards;
}
@keyframes contentFade {
  to { opacity: 1; }
}
```

**规则**：
- 骨架屏先淡出（0.3s），真实内容再淡入（0.4s，延迟0.15s）
- 两者有短暂重叠，避免空白闪烁
- 骨架屏隐藏后必须设置 `display: none` 或 `pointer-events: none`

## 三、转场动画

### 3.1 页面切换（Tab切换）

当前页面向左滑出，新页面从右滑入：

```css
.page-out {
  animation: pageOut 0.35s cubic-bezier(0.7, 0, 0.84, 0) forwards;
}
@keyframes pageOut {
  to { opacity: 0; transform: translateX(-30px); }
}

.page-in {
  animation: pageIn 0.4s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
@keyframes pageIn {
  from { opacity: 0; transform: translateX(30px); }
  to   { opacity: 1; transform: translateX(0); }
}
```

**规则**：
- 滑动距离：30px
- 旧页面先出，新页面再入（可重叠100ms）
- Tab切换优先使用淡入淡出（更轻量）

### 3.2 弹窗/模态框

从中心缩放展开：

```css
@keyframes modalIn {
  from { opacity: 0; transform: scale(0.9); }
  to   { opacity: 1; transform: scale(1); }
}
.modal-enter {
  animation: modalIn 0.3s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
```

蒙层淡入：

```css
@keyframes overlayIn {
  from { opacity: 0; }
  to   { opacity: 1; }
}
.overlay {
  background: rgba(0,0,0,0.4);
  animation: overlayIn 0.25s ease forwards;
}
```

### 3.3 底部面板（Bottom Sheet）

从底部滑出：

```css
@keyframes slideUp {
  from { transform: translateY(100%); }
  to   { transform: translateY(0); }
}
.bottom-sheet {
  animation: slideUp 0.4s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
```

**规则**：
- 必须有遮罩层（`rgba(0,0,0,0.4)`）
- 面板顶部圆角：20-28px
- 支持手势下滑关闭（拖拽时实时跟随手指）

## 四、微动效

### 4.1 按钮反馈

按下缩放：

```css
.btn:active {
  transform: scale(0.96);
  transition: transform 0.15s cubic-bezier(0.16, 1, 0.3, 1);
}
```

悬浮上浮（桌面端）：

```css
.btn-hover:hover {
  transform: translateY(-2px);
  box-shadow: 0 8px 24px rgba(var(--brand-rgb), 0.35);
  transition: all 0.25s cubic-bezier(0.16, 1, 0.3, 1);
}
```

### 4.2 图标动效

Tab切换图标缩放弹跳：

```css
.nav-tab.active .nav-tab-icon {
  animation: iconBounce 0.4s cubic-bezier(0.34, 1.56, 0.64, 1);
}
@keyframes iconBounce {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.2); }
  100% { transform: scale(1); }
}
```

心形/点赞放大：

```css
@keyframes heartPop {
  0%   { transform: scale(1); }
  25%  { transform: scale(1.3); }
  50%  { transform: scale(0.95); }
  100% { transform: scale(1); }
}
.like-active {
  animation: heartPop 0.4s cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

### 4.3 数字滚动

价格、统计数据变化时的数字滚动效果：

```css
@keyframes numberRoll {
  from { transform: translateY(100%); opacity: 0; }
  to   { transform: translateY(0); opacity: 1; }
}
.number-change {
  display: inline-block;
  animation: numberRoll 0.3s cubic-bezier(0.16, 1, 0.3, 1);
}
```

### 4.4 角标/红点呼吸

新消息红点的脉冲效果：

```css
@keyframes badgePulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.15); }
}
.badge-pulse {
  animation: badgePulse 2s ease-in-out infinite;
}
```

## 五、手势交互反馈

### 5.1 下拉刷新

弹性下拉 + 加载旋转：

```css
.pull-indicator {
  transition: transform 0.2s ease;
}
.pull-indicator.loading .spinner {
  animation: spin 0.8s linear infinite;
}
```

**规则**：
- 下拉距离超过 60px 触发刷新
- 释放后指示器保持可见，直到刷新完成
- 刷新完成后，指示器弹性回弹（0.3s）

### 5.2 上拉加载更多

底部加载提示：

```css
.load-more .spinner {
  animation: spin 0.8s linear infinite;
}
```

**规则**：
- 距离底部 50px 时触发加载
- 加载中显示旋转图标 + "加载中..."文字
- 加载完成时，新内容以 `cardEnter` 动画入场
- 无更多数据时显示 "没有更多了" 文字提示

### 5.3 滑动删除（列表项）

左滑露出删除按钮：

```css
.swipe-item {
  transition: transform 0.3s cubic-bezier(0.16, 1, 0.3, 1);
}
.swipe-item.open {
  transform: translateX(-80px);
}
```

**规则**：
- 滑动超过 40% 宽度自动展开
- 展开时露出红色删除按钮
- 点击其他区域或反向滑动收起

### 5.4 拖拽排序

拖拽时元素放大+阴影加深：

```css
.dragging {
  transform: scale(1.05);
  box-shadow: var(--shadow-lg);
  transition: transform 0.2s, box-shadow 0.2s;
  z-index: 100;
}
```

## 六、状态过渡

### 6.1 加载中 → 内容

骨架屏 shimmer 动画：

```css
@keyframes shimmer {
  0%   { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
.skeleton {
  background: linear-gradient(90deg, var(--border) 25%, #E8E8E8 50%, var(--border) 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
}
```

### 6.2 空状态

从加载到空状态的过渡：

```css
.empty-state {
  opacity: 0;
  animation: fadeIn 0.5s cubic-bezier(0.16, 1, 0.3, 1) 0.2s forwards;
}
```

**规则**：
- 空状态图标使用 Lottie 或 SVG 动画（轻轻浮动）
- 文案 + 操作按钮依次入场（stagger 100ms）

### 6.3 错误状态

错误提示的抖动效果：

```css
@keyframes shake {
  0%, 100% { transform: translateX(0); }
  20%      { transform: translateX(-6px); }
  40%      { transform: translateX(6px); }
  60%      { transform: translateX(-3px); }
  80%      { transform: translateX(3px); }
}
.error-shake {
  animation: shake 0.4s ease-in-out;
}
```

## 七、性能优化铁律

| 规则 | 说明 |
|:--|:--|
| **只动 transform 和 opacity** | 避免触发 layout 和 paint，使用 GPU 加速 |
| **will-change 谨慎使用** | 仅在动画开始前添加，动画结束后移除 |
| **避免同时动画过多元素** | 同一屏幕最多 10 个元素同时动画 |
| **减少层叠** | 动画元素尽量提升为独立合成层 |
| **prefers-reduced-motion** | 尊重用户系统设置，提供无动画降级 |

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 八、快速引用 CSS 类

在模板中预定义以下工具类：

```css
/* 入场 */
.anim-fade-in   { animation: fadeIn 0.4s cubic-bezier(0.16, 1, 0.3, 1) forwards; }
.anim-slide-up  { animation: slideUp 0.45s cubic-bezier(0.16, 1, 0.3, 1) forwards; }
.anim-scale-in  { animation: scaleIn 0.35s cubic-bezier(0.16, 1, 0.3, 1) forwards; }

/* 退场 */
.anim-fade-out  { animation: fadeOut 0.3s ease forwards; }
.anim-slide-out { animation: slideOut 0.35s cubic-bezier(0.7, 0, 0.84, 0) forwards; }

/* 微动效 */
.anim-bounce    { animation: bounce 0.4s cubic-bezier(0.34, 1.56, 0.64, 1); }
.anim-pulse     { animation: pulse 2s ease-in-out infinite; }
.anim-shake     { animation: shake 0.4s ease-in-out; }

/* 初始隐藏（配合入场动画） */
.opacity-0      { opacity: 0; }
```

## 九、动效自检清单

生成原型后检查：

- [ ] 页面首次加载有入场动画（非瞬间出现）
- [ ] 列表/卡片有交错入场（stagger）
- [ ] 骨架屏有 shimmer 动画，过渡到真实内容时无闪烁
- [ ] Tab 切换有平滑过渡（非瞬间跳转）
- [ ] 所有按钮有 `:active` 状态反馈（缩放或颜色变化）
- [ ] 弹窗/面板有展开/收起动画
- [ ] 下拉刷新有弹性动画和旋转指示器
- [ ] 上拉加载有旋转图标提示
- [ ] 无动画元素突兀出现（所有状态变化应有过渡）
