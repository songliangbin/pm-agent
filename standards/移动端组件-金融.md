# 移动端组件库 · 金融

> 主色倾向：深蓝金 `#1B3A6B`（主）+ `#C9A14A`（金点缀，财富感），稳重可信。导航默认 **B 传统固定底栏**。
> **本库是「组件零件清单」，不是固定首页模板**：做项目时先调研项目特性，规划出该项目的信息架构，再从下方清单挑选合适组件拼装；清单没有的组件按《移动端设计常识铁律》自绘，禁止因清单没有就不做。

## 组件零件清单（按需取用）

| 组件类名 | 视觉 | 适用场景 |
|:--|:--|:--|
| `.asset-total` 资产总览卡 | 总资产大字+今日盈亏+累计收益、深蓝底金字 | 资产总览 |
| `.yield-chart` 收益曲线 | 折线图(可切1月/3月/1年) | 收益走势 |
| `.asset-ring` 资产配置环形图 | 环形图+图例(配比) | 资产配置比例 |
| `.quick-action` 快捷入口宫格 | 宫格图标 | 转入/转出/还款/缴费入口 |
| `.product-card` 产品卡 | 名称+收益率+风险标签+期限 | 理财产品列表 |
| `.position-card` 持仓卡 | 名称+金额+收益率(红涨绿跌) | 持仓列表 |
| `.trade-item` 交易流水项 | 类型图标+金额+时间 | 交易流水 |
| `.risk-tag` 风险标签 | 低/中/高(绿/橙/红) | 风险等级标注 |
| `.detail-bar` 底部操作栏 | 固定底部毛玻璃 | 申购/赎回底部操作 |

## 关键铁律

- 主色深蓝金稳重专业，**避免花哨图标/动画**（金融要信任感）
- **中国红涨绿跌**：上涨红色、下跌绿色，语义色必须严格遵守，禁止反用
- 金额/收益数字**大字号 + tabular-nums 等宽**（对齐扫描）
- 收益用**图表可视化**（折线图/环形图），不纯数字列表
- 资产**分层展示**：总览(1秒可读) → 分类(2秒) → 详情(3秒)，禁止首页堆砌明细
- 风险等级**标签化**（R1-R5 颜色区分）+ 申购前风险提示
- 大额操作**双验证**（转账/申购需指纹+密码），体现安全合规
- **首页信息架构不固定**：根据项目调研从零件清单挑选组合（如财富管理平台「资产总览+收益曲线+产品推荐」，记账/信贷平台「额度+账单+还款」，不强制固定结构）
