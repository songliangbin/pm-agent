# 行业知识 — 本地生活 / 到家服务（家政/维修/美容/门店预约）

> **定位**：本地生活服务大类（家政、维修、美容美发、到店餐饮、宠物服务、洗护等），核心特征是"服务预约 + 门店/技师 + 评价信任"。生成该行业项目时步骤⑤前读取。
>
> **来源**：内置常规行业（2024-2026 认知）。

---

## 一、行业画像

| 维度 | 内容 |
|:--|:--|
| 目标用户 | 城市家庭/白领（家政保洁、维修）、本地消费者（到店/美容）、宠物主 |
| 核心场景 | ① 按需预约上门服务（保洁/维修/开锁）；② 到店预约（美发/美容/体检）；③ 就近找店（地图/距离）；④ 服务完成评价；⑤ 会员/次卡 |
| 商业模式 | 平台佣金抽成 + 商家广告 + 会员费；到店 O2O 靠核销抽佣 |
| 关键指标 | 预约转化率、上门准时率、完单率、复购率、差评率、商家覆盖密度 |

## 三、行业常见功能清单

### P0 必备
- [ ] 服务品类导航（家政/维修/美容等）
- [ ] 服务/门店列表（筛选：距离/评分/价格）
- [ ] 服务详情（价格、时长、包含内容、评价）
- [ ] 预约流程（选时间 → 选门店/技师 → 确认）
- [ ] 订单（预约单状态：待服务→进行中→已完成）
- [ ] 评价（服务后评价 + 追评）

### P1 常见
- [ ] 门店详情（位置/营业时间/服务项目）
- [ ] 技师列表（主页：经验/评价/档期）
- [ ] 优惠券/团购套餐
- [ ] 会员/次卡/储值
- [ ] 地图找店/距离排序
- [ ] 取消/改期预约

### P2 可选
- [ ] 在线支付押金/定金
- [ ] 服务进度实时跟踪
- [ ] 投诉/售后保障
- [ ] 邀请有礼

## 四、信息架构范式

- 首页：搜索服务 → 金刚区（品类大入口）→ 附近推荐门店/服务 → 营销卡（团购/券）→ 为你推荐
- 导航：底部 5 Tab——首页 / 分类 / 订单 / 消息 / 我的
- 关键二级页：服务详情（价格+时长+评价）、预约表单（日期/时段/门店/备注）、门店详情

## 五、易错产品逻辑（该行业高频坑）

| # | 易错点 | 行业原因 | 对策 |
|:--|:--|:--|:--|
| 1 | 预约时间选择弱 | 预约是核心，时间不可选=流程断 | 日期+时段双选、已满时段置灰（L7 选→sheet） |
| 2 | 门店/技师详情缺失 | 服务靠信任，无详情=不敢约 | 门店头+评价、技师主页必须完整（L4） |
| 3 | 预约单状态机断裂 | 取消/改期/爽约分支多 | 状态机完整：待服务→已完成/已取消/已爽约 |
| 4 | 服务后评价缺失 | 服务重口碑 | 完单后引导评价闭环 |
| 5 | 距离/位置感知弱 | 本地服务重就近 | 列表距离排序 + 位置显示 |
| 6 | 次卡/储值账目乱 | 余额/次数易错 | 余额扣减数据驱动，明细可查 |
