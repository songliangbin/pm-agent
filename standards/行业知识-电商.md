# 行业知识 — 电商（综合零售：服饰/3C/美妆/百货）

> **定位**：电商大类通用知识（服饰/3C/美妆/家居百货等）。生鲜/社区团购见独立文件 `行业知识-生鲜社区团购.md`。生成电商项目时步骤⑤前读取，作为信息架构调研起点。
>
> **来源**：内置常规行业（2024-2026 认知），竞品动态如需深度分析用户可显式要求联网核验。

---

## 一、行业画像

| 维度 | 内容 |
|:--|:--|
| 目标用户 | 全年龄消费者；按品类分化（服饰偏年轻女性、3C 偏男性/数码控、美妆偏 18-35 女性、百货全人群） |
| 核心场景 | ① 主动搜索比价购买；② 内容种草（直播/短视频/图文）后下单；③ 大促囤货（双11/618）；④ 复购补货（日用品）；⑤ 送礼 |
| 商业模式 | 交易佣金 + 广告（搜索/推荐竞价）+ 会员费 + 增值服务（保险/金融分期） |
| 关键指标 | GMV、转化率、客单价、复购率、退款率、退货率、物流时效 |

## 三、行业常见功能清单

### P0 必备
- [ ] 商品列表/详情（规格 SKU 选择、价格、评价、图文、参数）
- [ ] 购物车（多规格、编辑、合并结算）
- [ ] 下单结算（地址、运费、优惠券、支付）
- [ ] 订单（状态跟踪、取消、确认收货）
- [ ] 售后（退款、退货、换货）
- [ ] 搜索 + 分类导航

### P1 常见
- [ ] 优惠券/满减/平台补贴
- [ ] 收藏/关注店铺
- [ ] 评价（带图/追评）
- [ ] 购物车营销（凑单/加价购）
- [ ] 直播/短视频带货入口
- [ ] 消息通知（物流/促销）

### P2 可选
- [ ] 会员体系（等级/积分）
- [ ] 限时秒杀/大促会场
- [ ] 预售/定金
- [ ] 分销/拼团

## 四、信息架构范式

- 首页：搜索 → 金刚区（品类/功能）→ 轮播 Banner → 营销（秒杀/券）→ 推荐瀑布流（猜你喜欢）
- 导航：底部 5 Tab——首页 / 分类 / 购物车（角标）/ 消息 / 我的
- 关键二级页：商品详情（规格选择是关键交互）、订单列表（状态 Tab 筛选）、售后申请表单

## 五、易错产品逻辑（该行业高频坑）

| # | 易错点 | 行业原因 | 对策 |
|:--|:--|:--|:--|
| 1 | 规格 SKU 选择交互弱 | SKU 是电商核心，选错=无法下单 | 规格选择器必须可交互、默认选中、禁售规格置灰 |
| 2 | 商品图区空白 | 商品量大图缺 | 图区渐变占位 + 品类图标（M78） |
| 3 | 购物车角标/状态不同步 | 加购/删除后数量不联动 | 数据驱动重建购物车，角标实时 |
| 4 | 运费/优惠计算错 | 满减/运费叠加规则复杂 | 结算页金额联动重算，规则写进契约 |
| 5 | 售罄/库存无状态 | 下单失败体验差 | 售罄置灰 + 到货提醒 |
| 6 | 订单状态机断裂 | 退款/取消分支漏 | 状态机完整（pm-review R1 拦截假支付） |
