# 移动端组件库 · 医疗健康

> 主色倾向：医疗蓝绿 `#10B981`（专业可信，避免花哨）。导航默认 **B 传统固定底栏**。
> **本库是「组件零件清单」，不是固定首页模板**：做项目时先调研项目特性，规划出该项目的信息架构，再从下方清单挑选合适组件拼装；清单没有的组件按《移动端设计常识铁律》自绘，禁止因清单没有就不做。

## 组件零件清单（按需取用）

| 组件类名 | 视觉 | 适用场景 |
|:--|:--|:--|
| `.doctor-card` 医生卡 | 圆形头像+姓名+职称+医院+评分星+问诊按钮 | 医生列表/名医推荐 |
| `.dept-grid` 科室导航 | 宫格图标+文字 | 科室入口导航 |
| `.consult-card` 问诊卡 | 图文/电话/视频入口、主色渐变 | 问诊入口 |
| `.reg-card` 挂号卡 | 医院+科室+号源余量+时间 | 预约挂号 |
| `.health-data` 健康数据卡 | 数据+趋势图 | 健康数据展示 |
| `.report-card` 报告卡 | 名称+日期+状态 | 检验报告列表 |
| `.remind-card` 用药提醒 | 药品+剂量+时间+开关 | 用药提醒 |
| `.chart-bars` 趋势柱状图 | 柱状数据图 | 血压/血糖趋势可视化 |
| `.search-box` 搜索 | 症状/疾病/医生搜索 | 搜索入口 |

## 关键铁律

- 主色蓝绿专业，**避免花哨图标/动画**（医疗要可信、权威感）
- 问诊用**聊天式布局**（文字/语音/图片沟通）
- 健康数据用**图表可视化**（血压/血糖趋势折线）
- 医生/挂号必须有**真实筛选**（科室/医院/时间/价格）
- 隐私合规：电子病历分层展示（基本信息/诊断/治疗/检查），不堆砌
- **首页信息架构不固定**：根据项目调研从零件清单挑选组合（如在线问诊平台可用「搜索+问诊+科室导航+名医推荐」，体检预约平台可用「体检套餐+机构+报告」，不强制固定结构）
