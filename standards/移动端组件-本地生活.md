# 移动端组件库 · 本地生活

> 主色倾向：品牌色（餐饮暖橙 / 服务蓝绿）。导航默认 **A 毛玻璃悬浮胶囊**。
> **本库是「组件零件清单」，不是固定首页模板**：做项目时先调研项目特性，规划出该项目的信息架构，再从下方清单挑选合适组件拼装；清单没有的组件按《移动端设计常识铁律》自绘，禁止因清单没有就不做。

## 组件零件清单（按需取用）

| 组件类名 | 视觉 | 适用场景 |
|:--|:--|:--|
| `.home-stores` 店铺流 | 竖排店铺卡列表、间距10px | 门店/商家推荐 |
| `.store-card` 店铺卡 | 46px logo+名称+评分星+距离 | 店铺列表 |
| `.service-item` 服务卡 | 服务图+名称+价格+预约按钮 | 服务/项目列表 |
| `.promo-card` 券/团购 | 品牌渐变+券面额大号 | 优惠券/团购 |
| `.staff-card` 技师/员工卡 | 42px头像+姓名+简介 | 技师/员工展示 |
| `.shop-cats` 服务分类 | 分类Tab | 服务分类导航 |
| `.detail-bar` 底部操作栏 | 价格+预约/下单按钮固定底部毛玻璃 | 预约/下单 |
| `.order-card`/`.orders-tabs` | 订单卡+状态Tab | 订单列表 |
| `.search-box` 定位+搜索 | 定位+搜索框 | 首页定位+搜索 |

## 关键铁律

- 评分用**星标 SVG**（实心/空心组合，禁 emoji ⭐）
- 定位栏写真实城市/商圈名（禁"定位中…"占位）
- 预约/下单/评价**必须真实函数**（`submitReview`/`confirmMeetup` 等，禁 Toast 假按钮，M53 拦截）
- 服务图占位用内联 SVG 手绘（图区固定高 110px）
- **首页信息架构不固定**：根据项目调研从零件清单挑选组合（如宠物预约核销平台可用「定位+宠物档案+预约服务卡+门店核销+评价」，不强制「定位+搜索+金刚区+店铺流+服务流」）
