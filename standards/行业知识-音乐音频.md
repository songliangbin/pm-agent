# 行业知识 — 音乐音频（歌单/榜单/播放/歌手/播客）

> **定位**：音乐音频大类（在线音乐、歌单、榜单、歌手主页、播放器、播客/电台）。核心特征：播放体验、内容组织（歌单/榜单/专辑）、会员。生成该行业项目时步骤⑤前读取。
>
> **来源**：内置常规行业（2024-2026 认知）。

---

## 一、行业画像

| 维度 | 内容 |
|:--|:--|
| 目标用户 | 泛音乐用户（全年龄）、播客听众、音乐爱好者 |
| 核心场景 | ① 搜歌/听歌；② 刷歌单/榜单；③ 歌手/专辑浏览；④ 播客/电台订阅收听；⑤ 会员听高品质 |
| 商业模式 | 会员订阅 + 广告 + 直播打赏 + 数字专辑 |
| 关键指标 | MAU、人均收听时长、会员转化、完播率、留存 |

## 二、竞品格局

| 竞品 | 定位 | 信息架构特点 | 核心打法 | 差异化 |
|:--|:--|:--|:--|:--|
| QQ音乐 | 综合音乐 | 推荐 + 歌单 + 排行 | 版权全 + 会员 | 曲库 |
| 网易云音乐 | 社区音乐 | 推荐 + 歌单 + 评论 | 乐评社区 + 推荐算法 | 社区氛围 |
| 酷狗音乐 | 大众音乐 | 直播 + 听书 + 音乐 | 下沉市场 + 直播 | 大众化 |
| 汽水音乐 | 短视频音乐 | 单曲流 + 推荐 | 短视频算法听歌 | 推荐流 |
| 小宇宙 | 播客 | 订阅 + 播客单集 | 播客垂直 | 播客体验 |

## 三、行业常见功能清单

### P0 必备
- [ ] 播放器（播放控制 + 封面 + 歌词）
- [ ] 歌单列表/详情（歌曲列表）
- [ ] 榜单页
- [ ] 搜索（歌曲/歌手/歌单）
- [ ] 歌手主页（作品 Tab）
- [ ] 我的（收藏歌单/最近播放）

### P1 常见
- [ ] 播放队列/顺序播放
- [ ] 收藏/喜欢歌曲
- [ ] 评论（音乐社区特色）
- [ ] 下载/离线
- [ ] 会员入口

### P2 可选
- [ ] 电台/播客订阅
- [ ] 直播
- [ ] 场景电台（通勤/运动）
- [ ] 歌词滚动

## 四、信息架构范式

- 首页：搜索 → 金刚区（歌单/榜单/直播）→ 推荐歌单/新歌 → 每日推荐
- 导航：底部 5 Tab——首页 / 歌单 / 榜单 / 我的 / 消息（或首页/发现/音乐馆/我的）
- 关键二级页：播放页（全屏播放器）、歌单详情（歌曲列表）、歌手主页

## 五、易错产品逻辑（该行业高频坑）

| # | 易错点 | 行业原因 | 对策 |
|:--|:--|:--|:--|
| 1 | 播放器不可控 | 播放是产品核心 | 播放页必须有真实播放控制（L4） |
| 2 | 歌曲列表不可播 | 列表/播放脱节 | 点歌曲→播放页关联真实数据 |
| 3 | 歌词/封面缺失 | 播放体验不完整 | 播放页含封面+歌词（L4） |
| 4 | 收藏不联动 | 收藏是高频操作 | 就地切换收藏状态（L7/E） |
| 5 | 最近播放不记录 | 续听体验缺失 | 最近播放数据驱动 |
| 6 | 搜索无结果态 | 内容产品常见 | 空结果引导（R2 空态） |
