# 桌面端设计系统全局规范 v2.0
> 基于智慧餐饮平台管理端交互原型提炼的设计系统
> Agent 生成桌面端原型时必须遵循此规范

## 一、配色体系（CSS 变量）

### 1.1 主色方案

```css
:root {
  /* 布局尺寸 */
  --sidebar-w: 220px;
  --sidebar-collapsed-w: 64px;
  --header-h: 56px;

  /* 主色 */
  --accent: #5c6cf0;        /* 主色：按钮、链接、活跃态 */
  --accent-hover: #6d7bf7;  /* 主色 hover：比主色稍亮 */
  --accent-bg: #eef0fd;     /* 主色浅背景 */
  --accent-border: #d4d8f7; /* 主色边框 */

  /* 语义色 */
  --green: #10b981;         /* 成功 */
  --green-bg: #ecfdf5;      /* 成功背景 */
  --red: #ef4444;           /* 错误 */
  --red-bg: #fef2f2;        /* 错误背景 */
  --amber: #f59e0b;        /* 警告 */
  --amber-bg: #fffbeb;     /* 警告背景 */
  --blue: #3b82f6;          /* 信息 */
  --blue-bg: #eff6ff;       /* 信息背景 */

  /* 中性色 */
  --text: #111827;          /* 主文字 */
  --text2: #4b5563;         /* 次文字 */
  --text3: #9ca3af;         /* 辅助文字 */
  --border: #e5e7eb;        /* 边框 */
  --border-light: #f3f4f6;  /* 浅边框 */
  --bg: #f5f6f8;            /* 页面背景 */
  --card: #ffffff;          /* 卡片背景 */

  /* 侧边栏专用 */
  --sidebar-bg: #090a0f;    /* 侧边栏深色背景 */
  --sidebar-text: #8b8fa7;  /* 侧边栏文字 */
  --sidebar-hover: #1a1c26; /* 侧边栏悬停 */
  --sidebar-active: rgba(92,108,240,.12); /* 侧边栏选中背景 */

  /* 圆角 */
  --radius-sm: 8px;         /* 小圆角：按钮、输入框 */
  --radius: 12px;           /* 标准圆角：卡片、弹窗 */
  --radius-lg: 14px;        /* 大圆角：登录卡片 */
  --radius-xl: 20px;        /* 特大圆角 */

  /* 阴影（复合双层 — T2 铁律：所有阴影必须双层叠加） */
  --shadow-sm: 0 1px 2px rgba(0,0,0,.04), 0 1px 4px rgba(0,0,0,.02);
  --shadow: 0 1px 3px rgba(0,0,0,.04), 0 1px 2px rgba(0,0,0,.06);
  --shadow-md: 0 4px 12px rgba(0,0,0,.06), 0 1px 3px rgba(0,0,0,.04);
  --shadow-lg: 0 12px 40px rgba(0,0,0,.12), 0 4px 12px rgba(0,0,0,.05);
  --shadow-xl: 0 24px 56px rgba(0,0,0,.16), 0 8px 24px rgba(0,0,0,.08);
}
```

### 1.2 主色替换规则

Agent 根据项目类型替换 `--accent` 和 `--accent-hover`：

| 项目类型 | 主色 | 深色 |
|:--|:--|:--|
| SaaS/工具 | #5c6cf0 | #4a5bd8 |
| 数据/金融 | #1e40af | #1e3a8a |
| 电商/零售 | #f97316 | #ea580c |
| 医疗/健康 | #10b981 | #059669 |
| 教育/知识 | #8b5cf6 | #7c3aed |

其余语义色、中性色、阴影保持不变。

## 二、排版体系

### 2.1 字号层级

| 层级 | 字号 | 字重 | 用途 |
|:--|:--|:--|:--|
| 页面标题 | 22px | 700 | 页面主标题（letter-spacing: -0.3px） |
| 区域标题 | 15-17px | 600 | 卡片/区块/弹窗标题 |
| 正文 | 14px | 400 | 表格内容、表单标签 |
| 辅助 | 12-13px | 400 | 时间、备注、描述 |
| 迷你 | 11px | 600 | 分组标题、表头（大写+字间距） |

行高：数字 1.0 / 标题 1.3 / 正文 1.5 / 辅助 1.4

### 2.2 数字等宽

KPI 数字、表格中的金额、统计数据必须使用：
```css
font-variant-numeric: tabular-nums;
```

## 五、阴影体系（复合双层）

**铁律：所有阴影必须使用双层 box-shadow，单层阴影质感断崖下降。**

| 变量 | 用途 | 值 |
|:--|:--|:--|
| `--shadow-sm` | 微浮起、小元素 | `0 1px 2px rgba(0,0,0,.04), 0 1px 4px rgba(0,0,0,.02)` |
| `--shadow` | 标准卡片 | `0 1px 3px rgba(0,0,0,.04), 0 1px 2px rgba(0,0,0,.06)` |
| `--shadow-md` | 悬浮卡片 | `0 4px 12px rgba(0,0,0,.06), 0 1px 3px rgba(0,0,0,.04)` |
| `--shadow-lg` | 弹窗、抽屉 | `0 12px 40px rgba(0,0,0,.12), 0 4px 12px rgba(0,0,0,.05)` |
| `--shadow-xl` | 大型模态框 | `0 24px 56px rgba(0,0,0,.16), 0 8px 24px rgba(0,0,0,.08)` |

## 六、核心组件规范

### 6.1 侧边栏导航

- 宽度：`var(--sidebar-w)` = 220px（展开）/ 64px（折叠）
- 背景：`var(--sidebar-bg)` = `#090a0f`，右侧 1px 边框 `rgba(255,255,255,0.06)`
- Logo 区：高度 56px，底部 1px 分割线 `rgba(255,255,255,0.04)`
- 导航分组标题：11px，font-weight 600，`color: #4b5065; text-transform: uppercase; letter-spacing: 0.8px`
- 导航项：高度 40px，padding 9px 12px，border-radius `var(--radius-sm)`
  - 默认：`color: var(--sidebar-text)`，hover: `background: var(--sidebar-hover); color: #e4e5ec`
  - 活跃态：`background: var(--sidebar-active); color: #c7d2fe; border-left: 3px solid var(--accent)`（左侧主色条）
- 图标：18-20px，flex-shrink: 0
- 折叠态：文字隐藏，仅保留图标，悬停时 tooltip 显示名称
- 底部：折叠按钮 + 版本信息

### 6.2 顶部 Header

- 高度：`var(--header-h)` = 56px，白色背景 `var(--card)`，底部 1px 边框 `var(--border)`
- 左侧：面包屑（首页 / 当前页），字号 13px
- 右侧：搜索框 + 通知图标（带 badge 红点）+ 用户头像（30x30，圆角 8px）+ 用户名下拉
- 固定在顶部，z-index 高于侧边栏

### 6.3 KPI 指标卡片

- 白色背景，圆角 `var(--radius)` = 12px，padding 20px 24px
- 顶部结构：**彩色圆底图标（36-40px）+ 标题（stat-label）+ 描述**
- **底部无数字**（与旧版不同）
- 图标底色对应语义色：蓝色（主色）/ 绿色（成功）/ 琥珀色（警告）/ 红色（错误）
- hover：`border-color: #d1d5db; box-shadow: var(--shadow-md); transform: translateY(-1px)`
- 可选：底部趋势文字（小号字 + 箭头图标）

### 6.4 数据表格

- 容器：白色背景，圆角 `var(--radius-lg)`，border 1px `var(--border)`
- 表头：`background: #f9fafb`，字号 11px，font-weight 600，`color: var(--text2)`，大写 + 字间距 0.2px，底部边框 1.5px solid `var(--border)`
- 行高：52px，字号 13.5px，`color: var(--text)`
- 悬停：`background: #f9fafb`
- 状态标签：圆角胶囊，语义色背景+文字
- 操作列：按钮紧凑排列（gap: 4-6px）
- 分页：底部，共 N 条 + 页码按钮组

### 6.5 筛选区

- 白色背景卡片内，padding 16px 20px
- flex 横排，gap 10px，align-items: center
- 搜索框：带左侧搜索图标，width 240px，height 36px
- 选择器：同输入框样式，appearance: none，自定义下拉箭头 SVG

### 6.6 表单组件

- 标签：13px，font-weight 500，`color: var(--text)`，margin-bottom 6px
- 必填标记：红色星号 `color: var(--red)`
- 输入框：height 38px，border 1.5px solid `var(--border)`，border-radius `var(--radius-sm)`，padding 0 12px
- 聚焦：`border-color: var(--accent); box-shadow: 0 0 0 3px rgba(92,108,240,.08)`
- 文本域：min-height 80px，padding 10px 12px，resize: vertical
- 选择器：同输入框，自定义下拉箭头
- 错误态：`border-color: var(--red)` + 红色提示文字 12px

### 6.7 按钮

| 类型 | 样式 |
|:--|:--|
| primary | `background: var(--accent); color: #fff; border-radius: var(--radius-sm); height: 36px; padding: 0 16px; font-weight: 500` |
| default | `background: var(--card); border: 1.5px solid var(--border); color: var(--text); border-radius: var(--radius-sm); height: 36px; padding: 0 16px` |
| ghost | `background: transparent; color: var(--text2); border-radius: var(--radius-sm); height: 36px; padding: 0 12px` hover: `background: #f3f4f6; color: var(--text)` |
| danger | `background: var(--red); color: #fff` hover: `#dc2626` |

### 6.8 弹窗 Modal

- 遮罩层：`position: fixed; inset: 0; background: rgba(0,0,0,.35); backdrop-filter: blur(4px); z-index: 1100`
- 弹窗主体：`background: var(--card); border-radius: var(--radius-lg); width: 540px; max-width: 94vw`
- 入场动画：`opacity: 0; transform: scale(.96) translateY(8px)` -> 正常
- 头部：标题（17px，font-weight 600）+ 关闭按钮（32x32，hover 浅灰背景）
- 内容区：padding 24px，max-height 60vh，overflow-y: auto
- 底部：操作按钮，右对齐，顶部边框 1px `var(--border-light)`
- 关闭方式：点击遮罩 / 点击 X 按钮 / 按 ESC

### 6.9 抽屉 Drawer

- 从右侧滑入，`position: fixed; top: 0; right: -600px; width: 600px; max-width: 100vw; height: 100vh`

- 遮罩层同弹窗
- 头部：padding 20px 24px，border-bottom 1px `var(--border-light)`
- 内容区：flex: 1，overflow-y: auto，padding 24px
- 底部：padding 16px 24px，border-top 1px `var(--border-light)`，按钮右对齐

### 6.10 Toast 通知

## 七、布局铁律

### 7.1 三栏布局结构

```
body (overflow: hidden, height: 100vh)
  +-- header (fixed/sticky, top:0, height:56px, z-index:50)
  +-- 主体容器 (margin-top:56px, height:calc(100vh-56px), overflow:hidden)
      +-- aside (fixed, left:0, top:56px, bottom:0, width:220px, overflow-y:auto)
      +-- main (margin-left:220px, overflow-y:auto, height:calc(100vh-56px))
```

### 7.2 防遮挡铁律

- header 高度 56px，所有内容区偏移必须 >= 56px
- main 内容区 `overflow-y: auto` 独立滚动
- 切换路由/Tab 时，`main.scrollTop = 0`（不是 `window.scrollTo`）
- 侧边栏 `overflow-y: auto` 独立滚动

## 八、页面类型规范

### 8.1 登录页

- **独立页面**，不包含侧边栏和 Header
- 背景：`#08090f` 深色
- 浮动光球动画（3 个 orb，CSS animation，blur 100px，opacity 0.25）
- 网格背景：`linear-gradient(rgba(255,255,255,.015) 1px, transparent 1px)`，mask radial-gradient
- 毛玻璃登录卡片：`background: rgba(255,255,255,.04); backdrop-filter: blur(40px); border: 1px solid rgba(255,255,255,.06); border-radius: var(--radius-xl)`
- 品牌区：渐变图标（56px，圆角 16px）+ 产品名称（22px，白色）+ 描述（13px，灰色）
- 表单字段：label 11px 大写灰色 + input 深色背景 + focus 主色边框
- 登录按钮：width 100%，height 46px，主色填充，hover 上移 + 阴影

### 8.2 工作台/仪表盘

- 面包屑 -> 页面标题 -> **KPI 卡片行**（4 列或自适应） -> 快捷入口卡片 -> 待办列表/最近动态
- KPI 卡片顶部：图标 + 标题 + 描述，**底部无大数字**

### 8.3 列表/表格页

- 面包屑 -> 标题 + 操作按钮（新增/导出） -> 筛选区 -> 表格 -> 分页

### 8.4 详情页（抽屉或页面）

- 面包屑 -> 标题 + 返回按钮 -> Tab 页签（基本信息/关联数据/操作记录） -> 内容区
- 信息展示使用 info-grid（2 列）

### 8.5 表单页

- 面包屑 -> 标题 -> 表单卡片（分区块，每区块带左侧主色条装饰） -> 底部按钮区
- 表单项 2 列 grid 布局

### 8.6 设置页

- 面包屑 -> 标题 -> 多个白色卡片（按模块分组）
- 每个设置项使用 settings-row 横排布局
