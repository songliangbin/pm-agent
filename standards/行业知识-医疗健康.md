# 行业知识 — 医疗健康（问诊/挂号/报告/用药/健康管理）

> **定位**：互联网医疗大类（在线问诊、预约挂号、报告查询、用药管理、健康档案、慢病管理）。核心特征：信任重、合规强、信息敏感、决策需专业背书。生成该行业项目时步骤⑤前读取。
>
> **来源**：内置常规行业（2024-2026 认知）。

---

## 一、行业画像

| 维度 | 内容 |
|:--|:--|
| 目标用户 | 患者及家属（求医问药）、慢病人群（长期管理）、亚健康/体检人群、孕产/儿童健康关注者 |
| 核心场景 | ① 轻症在线问诊（图文/电话/视频）；② 线下挂号预约；③ 检验报告查询解读；④ 慢病复诊开药/用药提醒；⑤ 健康档案/体检管理 |
| 商业模式 | 问诊服务费 + 处方药电商 + 体检/保险导流 + 医院 SaaS |
| 关键指标 | 问诊量、响应时长、挂号成功率、复诊率、处方转化率、合规通过率 |

## 三、行业常见功能清单

### P0 必备
- [ ] 在线问诊（图文/视频，医生接诊流程）
- [ ] 科室/医生列表（专业/医院/评价）
- [ ] 医生详情（资质、擅长、排班、患者评价）
- [ ] 挂号/预约（选科室→医生→时段→确认）
- [ ] 报告查询（报告列表 + 详情解读）
- [ ] 我的就诊记录

### P1 常见
- [ ] 用药提醒/用药日历
- [ ] 处方药购买（电子处方流转）
- [ ] 健康档案（历史问诊/报告归档）
- [ ] 体检套餐 + 报告
- [ ] 健康资讯/科普
- [ ] 在线支付（挂号费/问诊费）

### P2 可选
- [ ] 慢病管理（血压/血糖记录曲线）
- [ ] 家庭健康（家庭成员的档案切换）
- [ ] 疫苗预约
- [ ] 保险推荐

## 四、信息架构范式

- 首页：搜索（疾病/医生/科室）→ 金刚区（问诊/挂号/报告/用药）→ 推荐医生/医院 → 健康资讯
- 导航：底部 5 Tab——首页 / 问诊 / 报告 / 消息 / 我的
- 关键二级页：问诊会话（消息流+输入栏）、挂号确认（时段选择）、报告详情（指标解读）

## 五、易错产品逻辑（该行业高频坑）

| # | 易错点 | 行业原因 | 对策 |
|:--|:--|:--|:--|
| 1 | 医生接诊流程假 | 问诊是核心，无真实流转=演示失败 | 问诊会话必须真实收发消息（M53 聊天铁律） |
| 2 | 挂号时段不可选 | 挂号依赖时段，不可选=流程断 | 时段选择器 + 已满置灰 |
| 3 | 报告数字错乱 | 医疗数据敏感，错=严重事故 | 报告数据与列表一致，tab-nums 等宽（T5） |
| 4 | 隐私/脱敏不到位 | 患者信息敏感 | 手机号/病历脱敏（D36/C1-28） |
| 5 | 用药提醒静态 | 慢病管理核心是提醒 | 用药日历真实状态流转 |
| 6 | 医生资质缺失 | 医疗重信任背书 | 医生详情必须含资质/擅长/评价（L4） |
