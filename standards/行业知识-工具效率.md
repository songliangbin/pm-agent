# 行业知识 — 工具效率（记账/日程/待办/打卡/备忘录）

> **定位**：工具效率大类（记账、日程日历、待办清单、习惯打卡、备忘录、个人管理）。核心特征：轻量高频、数据个人化、极简体验。生成该行业项目时步骤⑤前读取。
>
> **来源**：内置常规行业（2024-2026 认知）。

---

## 一、行业画像

| 维度 | 内容 |
|:--|:--|
| 目标用户 | 自律/效率追求者（20-40）、记账习惯者、学生/上班族 |
| 核心场景 | ① 记账（支出/收入分类）；② 日程安排（日历视图）；③ 待办清单（勾选/截止）；④ 习惯打卡；⑤ 备忘录/灵感 |
| 商业模式 | 免费 + 高级功能订阅（多端同步/报表/去广告） |
| 关键指标 | DAU、留存（工具类核心）、使用频次、付费转化 |

## 三、行业常见功能清单

### P0 必备
- [ ] 记录列表（账目/待办/便签）
- [ ] 新增/编辑（表单页）
- [ ] 分类/标签
- [ ] 完成状态（勾选/打卡）
- [ ] 统计/报表（记账类核心）
- [ ] 我的（设置/数据）

### P1 常见
- [ ] 日历视图
- [ ] 搜索
- [ ] 提醒/通知
- [ ] 预算（记账）
- [ ] 多分类筛选

### P2 可选
- [ ] 多端同步
- [ ] 数据导出
- [ ] 主题/深色模式
- [ ] 打卡日历

## 四、信息架构范式

- 首页：当日概览（记录列表 / 今日待办）→ 快速新增（FAB）→ 分类入口
- 导航：底部 4-5 Tab——首页 / 记录 / 统计 / 我的（或 今日/清单/统计/我的）
- 关键二级页：新增记录表单、详情、统计报表页

## 五、易错产品逻辑（该行业高频坑）

| # | 易错点 | 行业原因 | 对策 |
|:--|:--|:--|:--|
| 1 | 新增流程假 | 记录是核心操作 | 新增表单真实校验+保存（R3） |
| 2 | 完成状态不联动 | 勾选/打卡是高频 | 就地切换状态（L7/E） |
| 3 | 统计数字错 | 工具核心是数据可信 | 统计由记录汇总 + tab-nums（T5） |
| 4 | 分类不可用 | 分类是组织核心 | 分类筛选真实生效（M19） |
| 5 | 空态缺失 | 新用户首屏常空 | 空态引导新增（R2） |
| 6 | 编辑无法回填 | 修改体验差 | 编辑表单回填原数据 |
