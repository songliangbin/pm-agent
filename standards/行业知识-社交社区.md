# 行业知识 — 社交社区（动态/关注/私信/话题/直播/UGC）

> **定位**：社交/社区大类（动态流、关注关系、私信、话题广场、直播、创作者）。核心特征：内容为王、关系链驱动、互动形式多样（赞/评/转/私信）。生成该行业项目时步骤⑤前读取。
>
> **来源**：内置常规行业（2024-2026 认知）。

---

## 一、行业画像

| 维度 | 内容 |
|:--|:--|
| 目标用户 | 年轻用户（18-30 为主）、内容消费者、创作者/达人、兴趣社群 |
| 核心场景 | ① 刷信息流（关注/推荐）；② 发布动态/内容；③ 互动（点赞/评论/转发）；④ 私信社交；⑤ 直播互动 |
| 商业模式 | 广告（信息流）+ 直播打赏抽成 + 电商带货 + 会员 |
| 关键指标 | DAU/MAU、人均时长、互动率（赞评转）、留存、创作者活跃 |

## 二、竞品格局

| 竞品 | 定位 | 信息架构特点 | 核心打法 | 差异化 |
|:--|:--|:--|:--|:--|
| 微信 | 熟人社交 | 消息+发现+朋友圈 | 关系链 | 熟人网络 |
| 小红书 | 种草社区 | 双列流 + 搜索 + 笔记 | 图文种草 + 社区 | 种草心智 |
| 抖音 | 短视频 | 单列流 + 关注/推荐 | 算法推荐 | 短视频 |
| 微博 | 广场社交 | 热搜 + 信息流 + 话题 | 公共议题 | 热点广场 |
| B站 | 兴趣社区 | 分区 + 视频流 + 弹幕 | 兴趣分区 + 弹幕文化 | 中长视频 |

## 三、行业常见功能清单

### P0 必备
- [ ] 信息流（推荐/关注 Tab）
- [ ] 内容详情（正文 + 图片/视频 + 互动区）
- [ ] 互动（点赞/评论/转发/收藏）
- [ ] 发布（图文/视频）
- [ ] 关注关系（关注/粉丝）
- [ ] 我的主页（头像/作品/关注/粉丝）

### P1 常见
- [ ] 私信/聊天
- [ ] 话题/广场
- [ ] 搜索（内容/用户/话题）
- [ ] 消息通知
- [ ] 创作者主页

### P2 可选
- [ ] 直播（画面 + 互动 + 打赏）
- [ ] 私域群组
- [ ] 电商带货
- [ ] 成长等级/勋章

## 四、信息架构范式

- 首页：顶部 Tab（关注/推荐）→ 信息流卡片 → 底部发布按钮
- 导航：底部 5 Tab——首页 / 发现 / 发布（FAB）/ 消息 / 我的
- 关键二级页：内容详情（互动区）、创作者主页（作品 Tab）、私信会话、话题页

## 五、易错产品逻辑（该行业高频坑）

| # | 易错点 | 行业原因 | 对策 |
|:--|:--|:--|:--|
| 1 | 互动假（赞无状态） | 互动是社区核心 | 点赞/收藏/关注就地切换真实状态（L7/E） |
| 2 | 发布流程假 | 发布是 UGC 源头 | 发布表单真实校验+成功反馈（R3） |
| 3 | 评论无法发 | 互动闭环断 | 底部输入条弹起 + 追加评论（M53 聊天铁律） |
| 4 | 信息流与详情脱节 | 内容关系断裂 | 列表数据驱动，详情与列表一致 |
| 5 | 私信无真实会话 | 社交核心是沟通 | 消息流真实收发（M53） |
| 6 | 关注/粉丝数不联动 | 关系数据断裂 | 关注后粉丝数联动更新 |
