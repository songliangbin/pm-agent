# 移动端组件库 · 电商

> 主色倾向：活力橙红 `#FF6B35`（可换项目品牌色）。导航默认 **A 毛玻璃悬浮胶囊**。
> **本库是「组件零件清单」，不是固定首页模板**：做项目时先调研项目特性，规划出该项目的信息架构，再从下方清单挑选合适组件拼装；清单没有的组件按《移动端设计常识铁律》自绘，禁止因清单没有就不做。

## 组件零件清单（按需取用）

| 组件类名 | 视觉 | 适用场景 |
|:--|:--|:--|
| `.home-search` 搜索栏 | 圆角搜索框 | 有商品/内容搜索需求 |
| `.home-cats` 金刚区 | 5列宫格、2.5D图标、渐变底 | 需要功能入口导航（≤8个满格） |
| `.banner-track` banner轮播 | 满宽大圆角、自动播放+圆点 | 运营活动展示 |
| `.home-tiles` 瓷片区 | 左主图2:3+右上下副图 | 重点活动/品类突出 |
| `.promo-card` 营销区 | 品牌渐变+倒计时 | 限时秒杀/促销 |
| `.waterfall` 瀑布流 | 双列CSS columns交错 | 商品/内容流 |
| `.product-card` 商品卡 | 圆角12px、图3:4、价格品牌色 | 商品列表/推荐 |
| `.member-card` 会员卡 | 金橙渐变、权益宫格4列 | 会员体系 |
| `.cart-item`/`.cart-bar` | 数量步进+结算栏贴底毛玻璃 | 购物车/下单 |
| `.order-card`/`.orders-tabs` | 订单卡+状态Tab | 订单列表 |
| `.shop-cats`/`.sub-cats` | 分类Tab+子类 | 分类导航 |
| `.search-box` 筛选 | 搜索+筛选 | 列表页筛选 |
| `.detail-hero` 详情主图 | 满宽主图区 | 商品详情 |
| `.detail-bar` 底部操作栏 | 固定底部毛玻璃 | 详情页底部购买 |

## 关键铁律

- 商品占位图**必须手绘内联 SVG**（禁 fa 占位，图区固定高 110px + flex 居中）
- 列表 ≥10 条数据驱动渲染（`renderXxx` 从 data 重建，禁止硬编码）
- 秒杀倒计时用 `data-countdown` 时间戳（模板 `initCountdown` 自动跑，勿自写计时器）
- 详情页若字段 >8 或含长描述 → 用二级子页面（`sub-page`），否则可弹窗
- **首页信息架构不固定**：根据项目调研从零件清单挑选组合（如宠物平台可用「定位+金刚区+预约服务卡+门店核销」，不强制「搜索+金刚区+banner+瀑布流」）
