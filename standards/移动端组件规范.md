# 移动端组件规范 v1.0（三位一体 + token 节省设计）

> 本文档定义移动端原型的「底座铁律 + 导航多模式 + 组件三位一体 + 行业按需加载」。
> 核心原则：**顶级 UI 细节拉满，但 token 按需消耗，绝不一次全量读进上下文**。

---

## 0. Token 节省设计（硬性，与 UI 质量同等重要）

### 0.1 按需加载分层（token 节省核心）

生成移动端时，子 Agent 读取清单（总量约 20KB，比旧方案 47KB 省一半）：

| 层 | 文件 | 大小 | 何时读 |
|:--|:--|:--|:--|
| 注入说明 | `templates/注入说明-移动端.md` | 15KB | 必读（含组件类清单 + M53-M65 防坑铁律） |
| 底座+导航 | 本文档 §1 / §2 | ≤2KB | 必读 |
| 行业组件 | `standards/移动端组件-{行业}.md` | ≤2KB | **只读步骤④选定行业那一份** |
| 质感/动效 | `standards/UI质感规范.md`、`动效规范.md` | 按需 | 需要质感细节时读 |

**省 token 三关键**（靠"禁读冗余大文件 + 行业按需"，不靠删防坑铁律）：
1. **禁读完整模板** `prototype-mobile.html`（27KB → 改读 15KB 注入说明）
2. **禁读完整标准** `原型-移动端标准.md`（20KB → 改读本文档 §1/§2）
3. **行业组件只读 1 份**（电商项目不读医疗/金融/本地生活）

### 0.2 组件"三位一体"精简表达法

每个组件只写三行，禁长篇：

```
类名：.xxx（含修饰类）
视觉：一句话（尺寸/圆角/颜色/阴影/字重，用 token 值）
交互：一句话（点击/滚动/状态变化/动画）
```

### 0.3 上下文预算表（子 Agent 单次生成移动端的 token 预算）

| 环节 | 预算 | 说明 |
|:--|:--|:--|
| 读规范（§0.1） | ≈20KB | 注入说明15KB + 底座导航2KB + 行业1份2KB |
| 产出注入文件 | ≤80KB | nav 3KB + main 40KB + subpages 30KB + data 6KB |
| 主 Agent 拼装 | 确定性脚本 | build-prototype.py，不消耗大模型 token |
| 验证 | 程序强制 | lint + browser-check，不靠 Agent 自觉读 |

## 1. 底座铁律（🔒 锁死，动工禁止改动）

以下组件是**铁律公共组件**，结构与 CSS 变量一律不改，改乱即失败（lint 强制）：

| 组件 | 关键点 | 守护 |
|:--|:--|:--|
| 手机模拟器 phone-frame | 390×844，外框 #1a1a2e，圆角 52px | F1/F5 |
| 灵动岛 dynamic-island | 120×34 黑胶囊 | F3 |
| 状态栏 status-bar | 高 54px，左时间右信号/WiFi/电量 | F3 |
| 微信胶囊 | 87×32，右上 | F4 |
| 顶部栏 top-bar | 48px 毛玻璃，返回+标题 | F6 |
| 二级子页 sub-page | 右滑入，独立导航，`.content` 外 | F7/M63 |
| CSS 变量 | --status-h:54 / --topbar-h:48 | F8 |

**红线**：重构只做「新增导航变体 / 新增行业组件 / 新增交互组件」，绝不改上表结构。每次动工后跑 `verify-all`（browser-check 真实点导航/切 Tab/验证底座结构）。

## 2. 导航模式（五选一，class 变体，不改底座）

底部导航 = `bottom-nav` 底座 + 模式 class 变体，五选一：

| 模式 | class | 形态 | 适用行业/调性 |
|:--|:--|:--|:--|
| **A 毛玻璃悬浮胶囊**（默认） | `bottom-nav`（无额外类） | 悬浮圆角胶囊 + 毛玻璃 + 渐变延伸 | 电商/内容/生活类，高级质感 |
| **B 传统固定底栏** | `bottom-nav nav-solid` | 贴底实色白底 + 顶部 0.5px 分隔线 | 金融/工具/企业类，稳重 |
| **C 中间凸起 FAB** | `bottom-nav nav-fab` | 中间凸出 44px 圆主按钮 | 发布/核心动作场景（已有） |
| **D 顶部 Tab 分段** | 独立组件 `.seg-tabs` | 页内标签切换（关注/推荐式） | 信息流/内容页内切换 |
| **E 抽屉式侧栏** | 独立组件 `.drawer` | 汉堡侧滑抽屉 | 复杂企业/多模块应用 |

**自动推荐逻辑**：行业→默认模式。电商/生活→A；金融/工具→B；有"发布"核心动作→C；信息流内容页→D；复杂企业→E。PM 可在风格决策步骤自选覆盖。

**实现约束**：A/B/C 是 `bottom-nav` 的 class 变体（底座结构不变，只切样式）；D/E 是新增独立组件（不碰 bottom-nav）。

## 3. 组件三位一体规范（11 类，精简）

> 每个组件给出「类名 + 视觉一句话 + 交互一句话」。视觉用 token 值，交互用一句话。

### 3.1 首页顶部栏（搜索区）
- 类名：`.home-search`（含搜索框 + 扫码 + 消息图标）
- 视觉：白底/毛玻璃，圆角 22px 搜索胶囊，图标 24px SVG
- 交互：**沉浸式**——下滑隐藏、上滑恢复；搜索框聚焦跳搜索子页

### 3.2 金刚区（快速入口）
- 类名：`.home-cats` / `.home-cat`（5 列宫格）
- 视觉：图标 2.5D 等轴测（45°俯视、主色≤3种）、渐变底、圆角 16px、文案 5 字内 11px
- 交互：点击跳对应子页/列表；≤8 个自动两行

### 3.3 Banner 轮播
- 类名：`.home-banner`（含 -bg/-content/-tag/-title/-sub）
- 视觉：大圆角 16px、满宽、图 2:1
- 交互：**自动轮播 + 圆点指示器 + 手动滑动**

### 3.4 瓷片区（橱窗）
- 类名：`.home-tiles` / `.tile-main` / `.tile-sub`
- 视觉：左主图（2:3）+ 右侧上下副图，固定色卡
- 交互：点击跳活动/商品

### 3.5 营销区
- 类名：`.promo-card`（秒杀/拼团/优惠券）
- 视觉：品牌色渐变卡、倒计时 `tabular-nums`、价格大号 700
- 交互：倒计时实时更新；点击跳活动

### 3.6 商品瀑布流
- 类名：`.waterfall` / `.waterfall-col` / `.product-card`
- 视觉：**双列瀑布流**，卡片圆角 12px，图 3:4，价格 700 品牌色
- 交互：懒加载 + 悬停加购 + 点击进详情

### 3.7 置顶按钮（回到顶部）⛔ 已废除（v5.41）
> **本组件已废弃，禁止生成**：PM 明确不要回到顶部按钮（踩坑库 D47），模板已移除；
> `agent-lint` **C1-31** 对 `back-to-top`/`backToTop` 等特征字符串直接判失败，
> 长列表滚动定位由页面内原生滚动承接。本节保留仅为防止旧资料误导——
> 任何"按本节实现回顶按钮"的产物都会被自身门禁打回。

### 3.8 消息页
- 类名：`.msg-list` / `.msg-item`（含 -icon/-body/-title/-content/-time）
- 视觉：分类 Tab + 未读红点徽章 + 会话行（头像 48px + 标题 + 摘要 + 时间）
- 交互：Tab 筛选；未读徽章随已读状态消失

### 3.9 会员页
- 类名：`.member-card` / `.member-benefit`
- 视觉：金橙渐变会员卡（大圆角 20px）、权益宫格、透明胶囊"开通"按钮
- 交互：点击开通弹支付/升级；权益点击跳详情

### 3.10 个人中心
- 类名：`.mine-header` / `.mine-menu` / `.mine-order-entry`（四段式，已规范）
- 视觉：深色沉浸 Header（渐变 + 白字 + 头像 56px）+ 数据卡 + 宫格 + 列表菜单
- 交互：各入口跳子页；退出登录确认

### 3.11 状态/加载
- 类名：`.skeleton` / `.pull-indicator` / `.load-more` / `.empty-state`
- 视觉：骨架屏 shimmer（品牌色淡灰）、下拉指示器、加载 spinner、空态插画
- 交互：首屏骨架屏→内容淡入；下拉刷新；上拉加载；空态/错误态平滑过渡
