# 移动端产品逻辑规范（常识库）

> **本库是移动端产品逻辑的唯一真相源**：入口映射（L1-L6）、操作形态（L7）、页面类型白名单、行业特化映射均以本库为准。其他规范（移动端设计常识铁律 / 移动端组件规范 / 行业组件库）与本库冲突时，**以本库为准**（SKILL.md「规范冲突裁决」）。
>
> **铁律：生成移动端首页/任何入口前，必须先读本规范第一章**（通用入口逻辑）+ 所属行业章节（行业特化）。违反任一条 = 产品逻辑错误，lint **C1-34/C1-35** 与 browser-check **B16** 会拦截，build 失败必须重做。
> **lint 已内置全部特征检测**，本规范是 agent 的"产品常识教材"——照表映射、照骨架建页，禁止图省事复用单一列表页。

---

## 第一章 七条逻辑铁律（L1-L7，违反任一条 = 构建失败）

| 编号 | 铁律 | 说明 |
|:--|:--|:--|
| **L1** | **入口语义决定目标页** | 入口的文案/图标承载什么场景，就必须去什么页面。搜索框→搜索页、门店卡→门店详情、活动卡→活动页。**禁止全部入口指向同一个列表**（C1-35 拦截） |
| **L2** | **列表页只接受"类目"入口** | 只有金刚区类目（保洁/维修/月嫂）可进对应类目列表页；其他入口（搜索/Banner/活动/门店/券）不得直接进"全部列表" |
| **L3** | **运营内容必须有专题页** | 活动/秒杀/领券/拼团是独立专题页（倒计时 + 规则 + 参与项墙），不得省略、不得并进列表 |
| **L4** | **详情类入口必须进详情页** | 商品/服务/门店/歌单/课程/歌手/目的地等一律进详情页；详情页信息完整（头图 + 核心信息 + 评价/内容 + 操作闭环） |
| **L5** | **入口目标页必须真实存在** | 首页每个可点击入口的目标 sub-page 必须在项目里建成（C1-34 拦截"指向不存在页面"） |
| **L6** | **同组入口目标必须多样** | 同一入口组（banner 轮播组/金刚区/营销卡组）内，**每个入口必须指向不同的目标页**。banner1→活动A、banner2→商品详情、banner3→活动B；金刚区类目→各自类目列表。**同组目标去重后数量 < 入口数即 fail**（C1-35） |
| **L7** | **操作形态与语义匹配** | **读→二级页、写→独立表单页、选→sheet 弹窗、确认→modal、反馈→Toast、高频轻量→就地**。信息展示（关于/协议/帮助）与表单创建（新增/编辑地址）必须用独立二级页，**禁止信息展示用弹窗、禁止表单内联展开**（C1-36/C1-37 拦截）。详见第七章 |

## 第二章 通用入口逻辑（20+ 入口 → 目标页 → 必备特征）

> "必备特征"是 lint/browser-check 判断目标页类型是否正确的依据。目标 sub-page 必须含该类型特征元素。

| # | 入口（class） | 目标页类型 | 目标页必备特征 |
|:--|:--|:--|:--|
| 1 | 搜索框 `.home-search` / `.search-box` | 搜索页 `sub-search` | `<input` 输入框 + 热词/历史（`.hot-words`/`.hot-tags`） |
| 2 | Banner `.home-banner` / `.banner-track` | 活动专题页 `sub-activity*` | 倒计时（`.promo-timer` 或 `[data-countdown]`）+ 活动项墙 + 规则区 |
| 3 | 金刚区·类目 `.home-cat`（保洁/维修…） | 类目列表页 `sub-category*` | 分类 Tab（`.shop-cats`）+ 列表容器 |
| 4 | 金刚区·功能位（优惠券/订单/收藏/客服） | 对应功能页 | 券包页含券卡；订单页含状态Tab+订单卡；客服页含消息流+输入栏 |
| 5 | 营销卡 `.promo-card` / 秒杀/拼团/领券 | 对应专题页 | 秒杀→倒计时+秒杀墙；领券→券卡列表 |
| 6 | 商品/服务卡 `.product-card` | 服务详情 `sub-service-detail` | 头图（`.detail-hero`）+ 参数区 + 评价 + 底部操作栏（`.detail-bar`） |
| 7 | 门店/商家卡 `.store-card` | 门店详情 `sub-store-detail` | 门店头（logo+评分）+ 服务列表 + 评价区 |
| 8 | 内容/资讯/动态卡 | 内容详情 `sub-post` | 内容主体 + 点赞/评论互动区 |
| 9 | 我的中心 `.mine-*` 各入口 | 对应功能页 | 订单/券包/收藏/地址/设置各含自己的特征 |
| 10 | 聊天/客服入口 | 聊天会话 `sub-chat` | 消息流 + 输入栏（`.detail-bar`） |

## 第四章 行业特化映射（12 行业 + 兜底）

> 行业识别沿用 SKILL.md 行业识别规则；命中行业读对应行，未命中走第六章兜底。

### 医疗健康
科室→科室列表；医生→医生详情；挂号→挂号单；问诊→问诊会话；报告→报告详情；药品→药品详情

### 金融理财
资产→资产总览；理财/基金→产品详情；交易→交易记录；活动→活动专题；账单→账单详情

### 音乐/音频
歌单→歌单详情；排行榜→榜单页；歌手→歌手主页；歌曲→播放页；电台/播客→电台页；视频/MV→视频详情

### 社交/社区
动态→动态详情；关注→关注流；私信→聊天会话；话题→话题页；创作者→创作者主页；直播→直播间

### 内容/资讯
推荐→内容详情；热榜→榜单页；创作者→主页；专栏/专题→专栏详情；评论→评论区

### 出行/旅游
目的地→目的地专题；票务→票务列表；酒店/门票→详情页；行程→行程详情；游记→游记详情

### 教育/学习
课程→课程详情；我的课程→学习进度；练习→题库；直播课→直播间；错题→错题本；老师→老师主页

### 办公/协同

### 工具/效率
账单→账单详情；日程→日程详情；记录→记录详情；设置→设置页

### 房产/家居
楼盘→楼盘详情；房源→房源详情；小区→小区专题；装修案例→案例详情

## 第五章 弹层与交互规范（D44-D46 防护）

1. **sheet 必须在 `sheet-mask` 内**：新增 sheet 时把 `.sheet` 放进模板 `#sheetMask` 容器内（模板已内置 mask + sheet-default），**禁止平铺独立 `.sheet`**（C1-33 拦截）
2. **弹层内容禁滚动条**：禁止内联 `overflow-y:auto/scroll` 在弹层/内容区（C1-32 拦截）；内容由模板滚动容器统一处理
3. **跳转前必须关弹层**：任何 `openSubPage()`/`openServiceList()` 等跳转前必须先 `closeSheet()`/`closeModal()`，禁止弹层残留盖在下一页面前面（B13 拦截）

## 第六章 通用兜底规则（未识别行业）

未命中行业特化表时：
1. 用第二章通用入口逻辑 + 第三章页面类型白名单生成
2. 步骤④已执行的「信息架构调研」结果作为行业特化依据（调研产出首页信息架构 → 入口按调研结论映射）
3. 拿不准的入口目标：按 L6 做多样化的常识选择（如多个 banner 分别指向活动页/详情页），**不打断流程**，疑问记入交付说明

## 第七章 操作形态常识（L7 明细，5.18 新增）

> **操作形态 = 这个操作用什么形式呈现**。依据 iOS HIG：二级页面（push）用于信息层级，弹窗只给"弹窗内能独立完成"的自包含任务，创建/编辑/多步任务用独立页面，禁止弹窗套弹窗。

| 类 | 操作 | 正确形态 | 反面案例 |
|:--|:--|:--|:--|
| **A 信息展示** | 商品/服务/门店/订单/消息/内容详情 | 二级页 | 弹窗 ❌ |
| | **关于平台/用户协议/帮助中心/公告/规则说明** | **二级页**（sub-about） | **sheet ❌（C1-36 拦）** |
| | 大图/视频查看 | 全屏预览 | 弹窗 ❌ |
| **B 创建/编辑** | **新增/编辑地址、资料、发布、预约** | **独立表单页**（sub-xxx-form） | **列表内联展开 ❌（C1-37 拦）** |
| | 认证/新人引导 | 分步表单页 | 弹窗塞多步 ❌ |
| | 设置·开关类 | 就地 | 跳页 ❌ |
| | 设置·修改类（昵称/密码/绑定） | 表单二级页 | 内联 ❌ |
| **C 快速选择** | 选优惠券/选地址/选支付方式/选时间 | sheet 弹窗 | 跳新页 ❌ |
| | 筛选/排序 | 弹窗/抽屉/顶部筛选条 | 跳新页 ❌ |
| | 日期/时间 | 底部选择器 | 页面 ❌ |
| | 单条数据更多操作 | action sheet | 二级页 ❌ |
| **D 确认/反馈** | 删除/取消/退出等危险操作 | modal 弹窗 | 无确认直接执行 ❌ |
| | 操作成功/失败 | Toast | 弹窗 ❌ |
| **E 就地高频** | 收藏/点赞/关注/数量增减 | 就地 | 跳页 ❌ |

**决策框架**（agent 判断用）：
```
1. 弹窗内能否独立完成？ 否 → 二级页（信息/表单）
2. 任务是否复杂/多步/字段多？ 是 → 独立表单页
3. 是否产生层级（详情/子页）？ 是 → 二级页，禁止弹窗套弹窗
4. 是否轻量临时选择？ 是 → sheet 弹窗
5. 是否确认/反馈？ → modal / Toast
6. 高频轻量？ → 就地
```

## 第八章 列表与内容交互常识（5.18 新增）

| 场景 | 行业惯例 | 反面案例 |
|:--|:--|:--|
| 列表可删除/置顶/标已读 | 左滑操作（或编辑态批量操作） | 仅弹窗内删除 ❌ |
| 批量管理 | 编辑态 + 多选 | 无 ❌ |
| 长列表（≥ 一屏） | 下拉刷新 + 上拉加载更多 | 一次性全渲染无加载 ❌ |

| 层 | 覆盖 | 拦截机制 |
