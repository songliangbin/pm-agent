# 行业知识 — 金融理财（资产/理财/基金/交易/记账）

> **定位**：金融大类（理财、基金、股票交易、记账、信贷）。核心特征：数字敏感、合规强、信任极重、风险提示必要。生成该行业项目时步骤⑤前读取。
>
> **来源**：内置常规行业（2024-2026 认知）。

---

## 一、行业画像

| 维度 | 内容 |
|:--|:--|
| 目标用户 | 理财人群（25-45 中产）、投资交易者、记账习惯者、借贷需求者 |
| 核心场景 | ① 查看资产总览/收益；② 购买理财/基金；③ 股票交易（行情/下单）；④ 记账/预算管理；⑤ 贷款/信用卡还款 |
| 商业模式 | 管理费/申购费 + 交易佣金 + 息差 + 数据服务 |
| 关键指标 | AUM（管理资产）、MAU、转化率、留存、收益稳定性、合规通过率 |

## 三、行业常见功能清单

### P0 必备
- [ ] 资产总览（总资产/今日收益/累计收益）
- [ ] 理财产品列表（收益/期限/风险等级）
- [ ] 产品详情（业绩基准、历史收益、风险提示）
- [ ] 购买/赎回流程
- [ ] 交易/收益明细
- [ ] 我的持仓

### P1 常见
- [ ] 基金/股票行情（自选 + 走势图）
- [ ] 买入卖出下单
- [ ] 记账（分类 + 明细）
- [ ] 收益曲线/资产趋势图
- [ ] 风险测评
- [ ] 银行卡/账户管理

### P2 可选
- [ ] 定投计划
- [ ] 组合投资/智能投顾
- [ ] 贷款/信贷产品
- [ ] 理财社区/资讯

## 四、信息架构范式

- 首页：资产总览（大字数字）→ 金刚区（理财/基金/记账/信贷）→ 推荐产品 → 收益动态
- 导航：底部 5 Tab——首页 / 产品 / 行情 / 明细 / 我的
- 关键二级页：产品详情（收益+风险+购买）、交易确认（金额+密码）、持仓明细

## 五、易错产品逻辑（该行业高频坑）

| # | 易错点 | 行业原因 | 对策 |
|:--|:--|:--|:--|
| 1 | 数字错乱/不对齐 | 金融数字敏感，抖动=不专业 | 全站金额 tab-nums 等宽（T5） |
| 2 | 资产与明细不一致 | 总览/明细脱节=信任崩塌 | 数据驱动：总览由明细汇总 |
| 3 | 购买流程假 | 下单无真实状态流转 | 购买→确认→成功/失败 完整闭环（R1） |
| 4 | 风险提示缺失 | 合规要求，无提示=不合格 | 产品详情必须含风险等级提示 |
| 5 | 收益计算错 | 收益公式易错 | 收益=本金×利率×期限，契约写明 |
| 6 | 脱敏不到位 | 账户/手机敏感 | 手机号/卡号脱敏（D36/C1-28） |
