> PM Agent 生成桌面端/Web 端原型的完整技术标准
> 基于智慧餐饮平台管理端交互原型提炼

---

## 一、核心框架（铁律 F1-F4）

### 1.1 浏览器外壳（可选）

桌面端原型可以选择以下两种展示模式：

- **纯全屏**：无外壳，适合大屏展示和交互演示。原型直接占满整个视口，内容区最大化。
- **模拟浏览器窗口**：顶部模拟浏览器地址栏 + 圆角窗口边框，最大宽度 1440px。适合需要展示"产品形态"的场景。

> 选择依据：当 PM 未特别要求时，默认使用纯全屏模式。

### 1.2 三栏布局（铁律 F1）

桌面端原型必须严格遵循三栏布局结构，所有页面（登录页除外）共用同一套骨架：

```
┌──────────────────────────────────────────────────────────┐
│  Header（56px，fixed top，全宽）                          │
├──────────┬───────────────────────────────────────────────┤
│          │                                               │
│ Sidebar  │  Main Content（独立滚动）                      │
│ 220/64px │  padding: 24px                               │
│          │                                               │
│          │                                               │
└──────────┴───────────────────────────────────────────────┘
```

- **左侧导航（Sidebar）**：固定定位，宽度 220px（展开态）或 64px（折叠态），高度 100vh，独立滚动
- **顶部 Header**：固定定位，高度 56px，全宽，z-index 高于侧边栏
- **主内容区（Main）**：`margin-left: 220px`，`margin-top: 56px`，独立滚动（`overflow-y: auto`）
- 布局 CSS 必须遵守布局铁律（见 `standards/桌面端设计系统全局规范.md` §七）

**铁律**：三栏布局的结构不得在任何页面中被破坏。

### 1.3 路由模拟（铁律 F2）

桌面端使用**多页面路由模拟**：

- 每个页面是一个独立的 `<div class="page" id="page-{name}">`，默认 `display: none`
- 导航项的 `onclick="navigateTo('{name}')"` 触发路由切换
- `navigateTo()` 函数核心逻辑：
  1. 隐藏所有 `.page` 元素
  2. 显示目标页面
  3. 更新面包屑文本
  4. 重置 `main.scrollTop = 0`
  5. 更新侧边栏当前活跃项
- 面包屑随路由自动更新，格式：`首页 / 一级 / 二级`

### 1.4 登录页（铁律 F3）

登录页是独立页面，不包含侧边栏和 Header：

- 使用独立的 `<div id="loginPage">` 容器
- 背景：`#08090f` 深色 + 3 个浮动光球（CSS animation）+ 网格背景（radial-gradient mask）
- 登录卡片：毛玻璃效果 `backdrop-filter: blur(40px)`
- 登录成功后调用 `navigateTo('dashboard')`，同时隐藏登录页、显示三栏布局骨架
- 登录页不得出现"返回工作台"等入口

### 1.5 零 Emoji（铁律 F4）

**全站严禁 Emoji，所有图标必须使用内联 SVG。**

## 二、导航系统

### 2.1 侧边栏导航

- **宽度**：220px（展开态），64px（折叠态）
- **背景**：深色 `#090a0f`，右侧 1px 边框 `rgba(255,255,255,0.06)`
- **Logo 区**：高度 56px，内含 Logo SVG（32x32，圆角 10px，渐变背景）+ 系统名称
- **导航分组**：使用分组标题（`.nav-group-title`）分类，字体 11px，font-weight 600，大写，字间距 0.8px，`color: #4b5065`
- **导航项**：图标（18px）+ 文字，高度 40px，padding 9px 12px
- **活跃态**：左侧 3px 主色条 + 主色浅背景 `rgba(92,108,240,.12)` + 主色文字 `#c7d2fe`
- **悬停态**：`background: #1a1c26; color: #e4e5ec`
- **折叠态**：仅显示图标，文字隐藏，过渡动画 `transition: width .25s cubic-bezier(.4,0,.2,1)`
- **底部**：折叠按钮 + 版本信息/退出

### 2.2 顶部 Header

- **高度**：56px，白色背景，底部 1px 边框 `var(--border)`
- **左侧**：面包屑（首页 / 当前页），13px
- **右侧**：全局搜索（搜索图标 + 输入框）+ 通知铃铛（带 badge 红点）+ 用户头像（30x30，圆角 8px，姓名首字母）+ 用户名下拉菜单
- **用户下拉菜单**：个人中心、账号设置、退出登录

### 2.3 面包屑

- 自动随路由更新，格式：`首页 / 一级页面 / 二级页面`
- 字号 13px，颜色 `var(--text3)`
- 当前页加粗，`color: var(--text)`
- 各级可点击（除当前页外）

### 2.4 双模式侧边栏

模板支持两种导航模式，Agent 根据项目菜单数量自动选择：

#### 模式 A — 扁平模式（菜单 ≤ 10 项）

所有菜单项直接可见，无折叠功能。

```html
<div class="nav-group">
  <div class="nav-group-title">数据概览</div>
  <a class="nav-item active" data-page="dashboard">
    <i class="nav-icon fa-solid fa-chart-line"></i>工作台
  </a>
</div>
```

适用场景：菜单数量少，一目了然。

#### 模式 B — 树形模式（菜单 > 10 项）

一级菜单可点击展开/折叠二级菜单。

```html
<div class="nav-group">
  <div class="nav-item nav-parent" onclick="toggleNavGroup(this)">
    <i class="nav-icon fa-solid fa-briefcase"></i>
    <span>业务管理</span>
    <i class="nav-chevron fa-solid fa-chevron-down"></i>
  </div>
  <div class="nav-children">
    <a class="nav-item" data-page="goods">
      <i class="nav-icon fa-solid fa-box"></i>商品管理
    </a>
    <a class="nav-item" data-page="orders">
      <i class="nav-icon fa-solid fa-cart-shopping"></i>订单管理
    </a>
  </div>
</div>
```

**规则**：
- 二级菜单缩进 36px
- Chevron 图标旋转动画
- 默认展开第一个一级菜单
- 最多支持 2 级（不要三级）

**选择标准**：
| 条件 | 模式 |
|:---|:---|
| 一级+二级菜单总数 ≤ 18 个 | 扁平模式（全部直接显示） |
| 一级+二级菜单总数 > 18 个 | 树形模式（一级可展开/折叠二级） |

## 三、页面类型与骨架

### 3.1 工作台/仪表盘

```
┌─────────────────────────────────────────────────┐
│  KPI 卡片行（4 列 grid）                          │
│  [图标+标题+描述] [图标+标题+描述] ...            │
├────────────────────────┬────────────────────────┤
│  快捷入口卡片（2 列）    │  快捷入口卡片          │
├────────────────────────┴────────────────────────┤
│  待办列表               │  最近动态/活动记录     │
└────────────────────────┴────────────────────────┘
```

- **KPI 卡片**：白色背景，圆角 12px，padding 20px 24px
  - 顶部：彩色圆底图标（36-40px）+ 标题（stat-label，12.5px，`color: var(--text3)`）
  - **底部无大数字**（v3.0 变更）
  - 可选：底部趋势文字（小号字 + 箭头图标）
- **快捷入口卡片**：白色卡片，cursor pointer，点击跳转对应页面
- **待办列表 / 最近动态**：列表样式，每行一条，带时间戳和状态

### 3.2 列表/表格页

```
┌─────────────────────────────────────────────────┐
│  标题行：页面标题            [新增] [导出]          │
├─────────────────────────────────────────────────┤
│  筛选区：[搜索框] [下拉] [下拉] [搜索] [重置]      │
├─────────────────────────────────────────────────┤
│  表格                                            │
│  ☐ | 编号 | 名称 | 状态 | 创建时间 | 操作        │
│  ...                                             │
├─────────────────────────────────────────────────┤
│  分页：共 100 条  [<] 1 2 3 ... 10 [>]           │
└─────────────────────────────────────────────────┘
```

- **标题行**：页面标题（22px 加粗）+ 右侧操作按钮组
- **筛选区**：搜索框 + 下拉筛选 + 搜索按钮 + 重置按钮，水平排列
- **数据表格**：表头 `#f9fafb`，行高 52px，hover `#f9fafb`，操作列按钮紧凑（gap: 4px）
- **分页器**：总计条数 + 页码 + 上一页/下一页
- ⚠️ **手机号/电话脱敏铁律（D36，强制）**：列表/详情中任何手机号、电话号码字段**必须脱敏**——`13800138001`→`138****8001`、固话 `0571-88886666`→`0571-****6666`。模板已内置 `maskPhone()`，渲染时一律 `maskPhone(m.phone)`；data.js 若直接写明文 11 位手机号，lint **C1-28** 与 browser-check **B10** 会拦截交付

### 3.3 详情页/抽屉

两种详情展示模式：

**A. 弹窗 Modal**（适用于信息较少的详情）：
- 居中，最大宽度 540-560px，圆角 12px
- 标题 + 关闭按钮
- 内容区使用 info-grid（2 列）展示键值对
- 底部按钮区（操作按钮 + 关闭）

**B. 抽屉 Drawer**（适用于信息较多的详情）：
- 右侧滑入，宽度 480-600px，高度 100vh
- 顶部标题 + 关闭按钮
- 内容区使用 info-grid（2 列）分组展示
- 底部按钮区

抽屉适用于：门店详情、订单详情、用户详情等数据量较大的场景。

### 3.4 表单页

```
┌─────────────────────────────────────────────────┐
│  新增商品                   [取消] [保存]        │
├─────────────────────────────────────────────────┤
│  ┌─── 基本信息 ──────────────────────────────┐ │
│  │  商品名称  [________________]  商品分类 [v] │ │
│  │  商品价格  [________________]  库存数量 [__] │ │
│  └───────────────────────────────────────────┘ │
│  ┌─── 详细描述 ──────────────────────────────┐ │
│  │  商品描述                                 │ │
│  │  [____________________________]          │ │
│  └───────────────────────────────────────────┘ │
├─────────────────────────────────────────────────┤
│                              [取消] [保存并发布] │
└─────────────────────────────────────────────────┘
```

- **标题行**：页面标题 + 右侧取消/保存按钮
- **表单卡片**：白色卡片，分区块展示，每个区块有标题
- **表单项**：标签 + 输入框，2 列 grid 布局（`grid-template-columns: 1fr 1fr; gap: 16px`）
- **必填标记**：标签后加红色 `*`
- **底部按钮区**：固定在页面底部或卡片底部

### 3.5 设置页

- 面包屑 -> 标题 -> 多个白色卡片（按模块分组，如"平台信息"、"门店参数"、"订单参数"）
- 每个设置项使用 settings-row 横排布局
  - 左侧：label（13.5px，font-weight 500）+ hint（12px，灰色）
  - 右侧：input / select / toggle switch

### 3.6 登录页

- 深色背景 `#08090f`，全屏居中
- 3 个浮动光球（CSS keyframes animation，blur 100px，不同颜色）
- 网格背景（`linear-gradient` + `mask-image: radial-gradient`）
- 品牌区：渐变图标 + 产品名称 + 描述
- 毛玻璃登录卡片（`backdrop-filter: blur(40px)`，`rgba(255,255,255,.04)` 背景）
- 表单字段：11px 大写灰色 label + 深色背景 input + focus 主色边框
- 登录按钮：width 100%，主色填充，hover 上移 + 阴影

### 3.7 异常状态

所有列表页和详情页必须覆盖以下三种状态：

#### 空状态（empty-state）
- 居中对齐，图标 48px + 标题 + 描述 + 操作按钮
- 图标使用 FontAwesome（如 fa-inbox / fa-search / fa-folder-open）
- 标题："暂无数据" / "未找到结果"
- 描述：引导用户操作的文案
- 按钮（可选）："去添加" / "重新搜索"

#### 加载态（skeleton）
- 表格加载：skeleton-table（表头 + 3-4行骨架行）
- 卡片加载：skeleton-card（圆角卡片形状）
- 骨架使用渐变动画 shimmer 效果
- 颜色：`#f0f0f0` → `#e8e8e8` 渐变

#### 错误态（error-state）
- 居中对齐，红色图标 + 标题 + 描述 + 重试按钮
- 图标：fa-circle-exclamation
- 标题："加载失败"
- 按钮："重新加载"

## Step 4：生成原型 HTML

PM Agent 生成桌面端原型时，**不从头编写完整 HTML**，而是基于预置模板进行注入式填充。

### 模板注入流程

```
读取 templates/prototype-desktop.html（已有完整 CSS/JS/HTML 骨架）
  ↓
替换 5 个主色 CSS 变量（--accent 系列）
  ↓
替换文本占位符（项目名称/版本号等）
  ↓
生成侧边栏导航（NAV_START/END）
    → 根据菜单数量自动选择扁平模式或树形模式
  ↓
生成各页面内容（PAGE_START/END）
  ↓
填充数据（DATA_START/END）
  ↓
输出完整 HTML
```

#### 数据生成规范

Agent 使用模板内置的 `DataFactory` 对象生成表格数据，禁止手写死数据：

- **关联数据**：涉及跨实体关联的数据（如订单表的买家名、商品列表的发布者），统一从共享数据池引用
- **数据一致性**：同一个人名在用户表、订单表、日志表中使用同一个 `DataFactory.name()` 调用时，必须用缓存（`DataFactory.cache()` 方法）
- **状态顺序**：时间线数据的时间必须递增（如订单状态流：下单→支付→接单→配送→完成，每个时间比前一个晚）
- **数据量**：每个表格≥6行，每个下拉筛选至少3个真实选项

**数据工厂缓存方法**（Agent 在生成页面时使用）：

```javascript
// 在使用前创建缓存
DataFactory.cache = function(key) {
  if (!this._cache) this._cache = {};
  if (!this._cache[key]) this._cache[key] = this.name();
  return this._cache[key];
};
```

### 配色替换规范

模板中所有颜色已语义化，Agent 只需替换以下 5 个主色 CSS 变量：

| 变量名 | 说明 | 示例值 |
|:--|:--|:--|
| `--accent` | 主色 | `#5c6cf0` |
| `--accent-hover` | 主色 hover（比主色稍亮） | `#7b84f3` |
| `--accent-bg` | 主色 6% 透明度背景 | `rgba(92,108,240,0.06)` |
| `--accent-border` | 主色 15% 透明度边框 | `rgba(92,108,240,0.15)` |
| `--sidebar-active` | 侧边栏选中背景（主色 12% 透明度） | `rgba(92,108,240,0.12)` |

**约束**：
- 以上 5 个变量必须根据项目品牌色动态计算
- 其余所有颜色（语义色 green/amber/red/blue、中性色、阴影、圆角等）**全部固定**，不得修改
- 严禁在模板外额外写入硬编码颜色值

## 四、核心组件规范摘要

> 详细 CSS 实现请参考 `standards/桌面端设计系统全局规范.md`

### 4.1 KPI 卡片（v3.0 变更）

- 顶部结构：**彩色圆底图标 + 标题（stat-label）+ 描述**
- **底部无大数字**
- 图标底色：蓝色（主色）/ 绿色（成功）/ 琥珀色（警告）/ 红色（错误）

### 4.2 数据表格

- 容器：白色背景，圆角 12px，border 1px
- 表头：`background: #f9fafb`，11px，font-weight 600，大写
- 行高：52px
- 悬停：`background: #f9fafb`

### 4.3 按钮

| 类型 | 说明 |
|:--|:--|
| primary | 主色填充，白色文字 |
| default | 白底 + 1.5px 边框 |
| ghost | 透明底，hover 浅灰背景 |
| danger | 红色填充 |
| success | 绿色填充 |
| sm | 小尺寸（height 30px） |

### 4.4 标签 Tag

- 胶囊形状（border-radius: 20px）
- 前置 6px 圆点
- tag-done（绿）、tag-pending（黄）、tag-reject（红）、tag-info（蓝）、tag-neutral（灰）

### 4.5 弹窗 Modal

- 遮罩：`rgba(0,0,0,.35)` + `backdrop-filter: blur(4px)`
- 圆角 12px，宽度 540px
- 入场动画：`scale(.96) translateY(8px)` -> 正常

### 4.6 抽屉 Drawer

- 右侧滑入，宽度 480-600px
- 过渡：`right .3s cubic-bezier(.16,1,.3,1)`
- 遮罩同弹窗

### 4.7 Toast

- 右上角固定，圆角 8px
- 入场：`translateX(30px)` -> 正常
- 自动消失：2.5s

### 4.8 分类树 Cat Tree

- 节点可展开/折叠
- Chevron 图标旋转 90deg 动画
- 子节点 `max-height` 过渡动画
- hover 显示操作按钮（opacity 过渡）

### 4.9 信息展示 Info Grid

- 2 列网格
- info-section 分组，11px 大写标题
- info-item 键值对，label（`color: var(--text3)`）+ value（`color: var(--text)`）

### 6.11 行业扩展组件

对于特定行业的项目，Agent 应额外引入 `templates/desktop-extensions/{行业}.html` 中的组件。

| 行业 | 文件 | 额外组件 |
|:---|:---|:---|
| 电商 | ecommerce.html | 商品卡片、SKU选择器、订单时间线、物流追踪步骤、分类树 |
| 金融 | finance.html | 金额输入器、对账单、审批流卡片、统计卡、账户余额展示 |
| 教育 | education.html | 课程卡片、考试列表、成绩表格、排课日历、班级列表 |
| 医疗 | medical.html | 患者卡片、预约时间线、处方表单、挂号表格、检查报告 |

使用时将扩展 CSS 通过 `<style>` 注入到原型 `<head>` 中。

## 动效规范（质感增强）

### 页面切换
- 使用 `pageFadeIn` 动画（opacity 0→1, transform translateY 6px→0）
- 持续时间 250ms，ease 缓动
- 禁用动效：`@media (prefers-reduced-motion: reduce)`

### 列表逐行入场（stagger）
- 表格行或卡片列表使用 `.stagger-enter` 类
- 每行延迟 60ms（第1行0ms, 第2行60ms, 第3行120ms...）
- 配合 JS 在页面加载后批量添加 `.show` 类

### 弹窗
- 缩放 + 淡入（scale 0.96 → 1, opacity 0 → 1）
- 持续时间 200ms

### 侧边栏
- 导航项 hover 的 background 过渡 150ms
- 树形模式展开/折叠的 max-height 过渡 300ms

## 五、交互规范

### 5.1 路由切换

```javascript
function navigateTo(pageId) {
  document.querySelectorAll('.page').forEach(p => p.classList.remove('active'));
  const target = document.getElementById('page-' + pageId);
  if (target) target.classList.add('active');
  updateBreadcrumb(pageId);
  const main = document.getElementById('mainContent');
  if (main) main.scrollTop = 0;
  document.querySelectorAll('.nav-item').forEach(n => n.classList.remove('active'));
  const navItem = document.querySelector('.nav-item[data-page="' + pageId + '"]');
  if (navItem) navItem.classList.add('active');
}
```

**铁律**：页面切换时滚动重置必须是 `main.scrollTop = 0`。

## 六、数据模拟规范

桌面端原型的数据模拟必须遵循以下规范，确保原型看起来"像真的一样"。

### 6.1 表格数据

- **数量**：6-10 行示例数据（不得少于 5 行）
- **编号**：使用真实编号格式（如 `ST001`、`ORD-20240101-001`）
- **名称**：使用业务相关的真实名称（如"老刘家大锅饭"，而非"测试数据"）
- **金额**：真实金额格式，两位小数，千分位逗号（如 `1,280.50`）
- **时间**：`YYYY-MM-DD HH:mm` 格式
- **状态**：至少覆盖 3 种状态（见下表）

### 6.2 KPI 数据

- **数值**：真实合理的大小
- **趋势**：同比/环比使用真实百分比（如 `+12.5%`），配合上升/下降箭头
- **趋势颜色**：上升为绿色，下降为红色

### 6.3 用户信息

- **头像**：使用姓名首字母圆形头像（`background: var(--accent)`，白色文字）
- **姓名**：使用常见中文姓名
- **角色**：使用真实角色名（如"门店管理员"、"运营人员"）

### 6.4 状态分布

| 场景 | 推荐状态组合 |
|:--|:--|
| 订单管理 | 待支付、已支付、已发货、已完成、已取消 |
| 商品/门店管理 | 营业中、休息中、已封禁、草稿 |
| 用户管理 | 正常、已禁用、待审核 |
| 审批/入驻流程 | 待审核、已通过、已驳回 |
| 成员管理 | 正常、已禁用 |

## 八、质量门禁（桌面端专项）

每次原型生成完成后，Agent 必须逐项自检以下所有条目。

### 8.1 布局检查

- [ ] **三栏布局正确**：header 56px + sidebar 220px + main 独立滚动
- [ ] **滚动隔离**：切换页面时 `main.scrollTop = 0`
- [ ] **面包屑同步**：每次路由切换后自动更新
- [ ] **登录页独立**：不包含侧边栏和 Header，有光球动画和毛玻璃卡片
- [ ] **内容区 padding**：主内容区 padding 24px

### 8.2 质感检查

- [ ] **KPI 卡片无大数字**：顶部图标+标题，底部无 28px 大数字
- [ ] **表格行高 52px**：表头 11px 大写，`background: #f9fafb`
- [ ] **侧边栏深色**：`#090a0f` 背景，选中态左侧 3px 主色条
- [ ] **标签胶囊形状**：border-radius 20px，前置圆点
- [ ] **零 Emoji**：全站 SVG 图标
- [ ] **配色**：只替换 5 个主色变量，其余固定

### 8.3 功能检查

- [ ] **侧边栏导航**：点击可切换页面，活跃态正确
- [ ] **侧边栏折叠**：可收缩到 64px
- [ ] **弹窗**：打开/关闭正常，支持点击遮罩关闭
- [ ] **抽屉**：右侧滑入/滑出正常
- [ ] **Toast**：可显示并自动消失
- [ ] **登录页**：点击登录后跳转到工作台
- [ ] **侧边栏模式**：扁平模式（菜单少）或树形模式（菜单多），不可混用
- [ ] **树形模式**：Chevron 旋转动画正常，默认只展开第一个分组
- [ ] **登录后默认页**：`doLogin()` 必须调用 `switchPage('dashboard')`（或首个页面），确保登录后内容区不为空白

### 8.4 完整性检查

- [ ] **页面覆盖**：至少包含 5 个页面——工作台 + 列表页 + 详情页/抽屉 + 表单页 + 设置页 + 登录页
- [ ] **示例数据**：每个表格包含 6-10 行真实数据
- [ ] **状态覆盖**：至少包含 3 种不同状态的数据行
- [ ] **审核流程**（如有审核页）：通过/驳回/重新提交完整闭环

### 8.5 自检自动化

Agent 生成后**必须确保 `selfCheck()` 被自动调用**（在 doLogin() 或 DOMContentLoaded 中调用），不得仅定义而不执行。

```javascript
function selfCheck() {
  // 返回 {ok: boolean, msg: string}[]
  // 必检项：布局宽度 / 导航模式 / 无Emoji / 表格组件 / 登录页 / 弹窗系统 / Toast / DataFactory
}
```

**🔴 DataFactory 强制使用**：表格数据必须使用 `DataFactory` 生成，禁止手写死数据。DataFactory 必须在 demoData 之前定义。

**不允许出现的自检失败项**：
- 树形模式但菜单 ≤ 18 个（应该用扁平模式）
- 扁平模式但菜单 > 18 个（应该用树形模式）
- 导航/内容区使用了 Emoji 代替 SVG 图标
- 缺少登录页或弹窗系统
- 缺少 Toast 函数或 showToast 未定义
- 表格数据为硬编码（未使用 DataFactory）
- selfCheck 仅定义但未在页面加载时调用
- **doLogin() 未调用 switchPage()，导致登录后内容区空白**
- **树形模式下默认展开多个分组，导致用户感知"双击"问题**
