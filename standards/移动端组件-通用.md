# 移动端组件库 · 通用兜底

> 主色倾向：项目自定义。导航默认 **A 毛玻璃悬浮胶囊**（金融/工具类可改 **B 传统固定底栏** `nav-solid`）。
> **本库是「组件零件清单」，不是固定首页模板**：做项目时先调研项目特性，规划出该项目的信息架构，再从下方清单挑选合适组件拼装；清单没有的组件按《移动端设计常识铁律》自绘，禁止因清单没有就不做。

## 通用组件零件（模板已内置，按场景选用）

- 卡片 `.card-ui`；按钮 `.btn`/`.btn-primary`/`.btn-default`/`.btn-danger`/`.btn-block`/`.btn-sm`
- 标签 `.tag`/`.tag-ok`/`.tag-info`/`.tag-warn`/`.tag-danger`/`.tag-muted`/`.tag-neutral`
- 表单 `.form-group`/`.form-input`/`.form-options`/`.form-option`
- 列表按场景选：`.msg-list`(消息) `.staff-card`(员工) `.addr-card`(地址) `.todo-list`(待办)
- 状态：`.empty-state`(空态) `.skeleton`(骨架屏) `.pull-indicator`(下拉刷新) `.load-more`(上拉加载)
- 置顶按钮 `.back-to-top`（模板自动监听，**无需手写**）
- 工作台看板：`.work-header` + `.work-stats` + `.work-quick`（工具/管理类首页）
- 详情：`.detail-section` + `.detail-bar`（固定底部操作栏）
- 评价卡 `.review-card`（头像+昵称+星级SVG+内容+时间，电商/本地生活/医疗/金融通用）
- 优惠券卡 `.coupon-card`（券面额+名称+使用条件+领取，电商券/团购券/理财券通用）
- 认证/实名卡 `.verify-card`（图标+名称+描述+状态，金融实名/医疗实名/企业认证通用）
- 进度/状态流转 `.step-indicator`（`.step-node`/`.step-dot`/`.step-line`，订单状态/流程进度通用）
- 邀请卡 `.invite-card`（品牌渐变+标题+邀请码，邀请锁客/分享裂变通用）
- 通知/公告条 `.notice-bar`（图标+单行文字，系统公告/活动通知通用）
- 搜索历史 `.search-history`（`.sh-item` 标签，搜索页历史记录通用）
- 底部弹层 `.sheet`（`.sheet-mask`+`.sheet`+`.sheet-handle`，`openSheet(id)`/`closeSheet()` 控制，筛选/操作/分享面板）
- 弹窗 `.modal`（`.modal-mask`+`.modal`+`.modal-title`+`.modal-content`+`.modal-actions`，`openModal(id)`/`closeModal()` 控制，确认/提示/输入）
- 开关 `.switch`（`<div class="switch"><span></span></div>` + `toggleSwitch(this)`，设置项开关）
- 评分输入 `.rating`（内含 SVG 星，`rateStar(el, i)` 点击打分，配合 `.review-card` 展示）
- 进度条 `.progress`（`.progress-bar` + `.progress-text`，认证/下载/课程进度）
- 加载态 `.loading`（`.loading-spinner`，按钮加载/页面加载）

## 导航模式选择

| 场景 | 模式 |
|:--|:--|
| 内容/生活/社交 | A 毛玻璃悬浮胶囊（默认） |
| 金融/工具/企业 | B 传统固定底栏（`navMode: "solid"`） |
| 有"发布"核心动作 | C 中间凸起（`navMode: "fab"`） |
| 信息流页内切换 | D 顶部Tab分段 `.seg-tabs` |
| 复杂企业多模块 | E 抽屉侧栏 `.drawer`（`openDrawer`/`closeDrawer`） |

## 关键铁律

- 优先用模板内置组件类，**自创类名须符合设计规范**（见《移动端设计常识铁律》组件绘制规范）
- 关键业务**真实函数化**（M53 白名单：订单/发布/钱包/评价/地址必须数据驱动重建，禁 doAction 假按钮）
- 二级子页面必须放 `.content` 外（M63）
- **首页信息架构不固定**：根据项目调研规划，从零件清单挑选组合，禁止套固定模板
