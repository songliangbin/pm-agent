## 一、核心框架（铁律 F1-F3）

### 1.1 手机模拟器（phone-frame）
- 尺寸：390×844（phone-screen），含边框 410×864
- 外框：深色 #1a1a2e，圆角 52px，padding 10px
- 阴影：0 25px 80px rgba(0,0,0,0.25) + inset border
- 缩放：CSS 变量 --phone-scale，JS adjustScale()

### 1.2 灵动岛（dynamic-island）
- 120×34，黑色背景，圆角 20px
- position: absolute，顶部居中（top: 10px），z-index: 200

### 1.3 状态栏（status-bar）
- 高度 54px（`--status-h: 54px`），z-index: 300
- **左：实时时间（15px, 600）**
- **右：信号+WiFi+电量 SVG 图标**（与微信胶囊共存或单独显示，取决于页面导航栏设计）
- padding: 0 26px 8px
- **🔴 状态栏右侧图标为强制公共组件**，Agent 不得删除或省略

### 1.4 微信胶囊按钮（铁律 F4）
- 87×32，圆角 16px，border: 0.5px solid rgba(0,0,0,0.12)
- 背景：rgba(255,255,255,0.35)
- 左半：3个圆点（3.5px），右半：圆形关闭圈
- position: absolute; top: calc(var(--status-h) + 8px); right: 12px; z-index: 101

### 1.5 顶部导航栏（top-bar）（🔴 铁律 F6，强制公共组件）

**每个移动端原型必须包含顶部导航栏，Agent 不得删除或省略。**

- 位置：`position: absolute; top: var(--status-h); left: 0; right: 0`
- 高度：48px（`--topbar-h: 48px`）
- z-index: 100
- 半透明毛玻璃背景：`rgba(249,250,251,0.85)` + `backdrop-filter: blur(20px)`
- 底部边框：`0.5px solid rgba(0,0,0,0.04)`
- 左侧：返回按钮（36×36，默认隐藏 `display:none`）+ 标题（16px, 600）
- 右侧：可放操作按钮或留空
- 返回按钮：左箭头 SVG，`stroke-width: 2.5`
- 标题通过 `id="topBarTitle"` 动态更新

**HTML 结构（Agent 禁止修改结构，只可修改标题文字）：**
```html
<div class="top-bar" id="topBar">
  <div class="top-bar-left">
    <button class="back-btn" id="backBtn" style="display:none" onclick="goBack()">
      <svg viewBox="0 0 24 24"><polyline points="15 18 9 12 15 6"/></svg>
    </button>
    <div class="top-bar-title" id="topBarTitle"><span>{{首页标题}}</span></div>
  </div>
</div>
```

### 1.6 二级子页面导航（🔴 铁律 F7，强制公共组件）

**每个二级子页面必须使用统一的 sub-page 结构，包含独立导航栏。**

- 容器：`.sub-page`，绝对定位，`inset: 0`，右滑入动画（`translateX(100%) → translateX(0)`）
- 过渡：`0.35s cubic-bezier(0.16,1,0.3,1)`（iOS 弹性缓动）
- 子页面导航栏 `.sub-page-nav`：
  - 左侧：返回按钮（32×32，白色背景，10px 圆角，微阴影）
  - **标题绝对居中**：`position: absolute; left: 50%; transform: translateX(-50%)`
  - 字号 17px, 600
- 子页面内容区 `.sub-page-body`：`flex: 1; overflow-y: auto`

**HTML 结构：**
```html
<div class="sub-page" id="sub-{name}">
  <div class="sub-page-header">
    <div class="sub-page-nav">
      <div class="sub-page-back" onclick="closeSubPage('sub-{name}')">
        <svg viewBox="0 0 24 24"><polyline points="15 18 9 12 15 6"/></svg>
      </div>
      <span class="sub-page-title">{页面标题}</span>
    </div>
  </div>
  <div class="sub-page-body">
    <!-- 页面内容 -->
  </div>
</div>
```

### 1.7 CSS 变量（🔴 铁律 F8，强制）

`:root` 中必须包含以下设备参数变量，Agent 不得删除：

```css
--phone-w: 390px;
--phone-h: 844px;
--status-h: 54px;
--topbar-h: 48px;
```

## 二、导航系统（铁律 I4）

### 2.1 底部毛玻璃悬浮导航
- position: absolute; bottom: 12px; left: 24px; right: 24px; height: 52px; z-index: 150
- 背景：`rgba(255,255,255,0.82)`
- **毛玻璃：`backdrop-filter: blur(20px) saturate(180%)`**（必须同时包含 blur 和 saturate）
- **边框：`border: 1px solid rgba(255,255,255,0.3)`**（毛玻璃必须有半透明边框增强质感）
- 圆角：26px, 阴影：`0 12px 40px rgba(0,0,0,0.12), 0 4px 12px rgba(0,0,0,0.05)`（XL 层级复合阴影）
- 隐藏动画：`.hide { transform: translateY(80px); opacity: 0; pointer-events: none }`

### 2.1+ 底部渐变背景（🔴 铁律 F9，强制组件）

> **铁律**：底部导航栏必须使用向上延伸的渐变背景，禁止内容直接硬截断在导航栏边缘。

**实现方式（严禁使用伪元素）**：
- **禁止**使用 `.bottom-nav::before` 在导航栏上方放置独立蒙版。渐变必须是导航栏自身 `background` 的一部分。
- 导航栏总高度：`116px`（按钮区 52px + 向上渐变延伸 64px）
- 对齐方式：`align-items: flex-end`（按钮固定在底部 52px 区域）
- 背景渐变：`linear-gradient(to top, rgba(249,250,251,0.92) 0%, rgba(249,250,251,0.92) 44%, rgba(249,250,251,0.82) 56%, rgba(249,250,251,0) 100%)`
  - **方向说明（禁止写反）**：`to top` = 从下往上，0%在底部（紧贴按钮区，最实），100%在顶部（远离按钮区，完全透明）。**严禁写成 `to bottom`**，否则效果相反。
- 导航项高度固定为 `52px`，确保按钮在实色区域内
- 隐藏动画位移量需配合总高度：`transform: translateY(130px)`

**CSS 示例**：
```css
.bottom-nav {
  position: absolute;
  bottom: 12px; left: 24px; right: 24px;
  height: 116px; /* 52px + 64px */
  display: flex;
  align-items: flex-end;
  justify-content: space-around;
  background: linear-gradient(to top,
    rgba(249,250,251,0.92) 0%,
    rgba(249,250,251,0.92) 44%,
    rgba(249,250,251,0.82) 56%,
    rgba(249,250,251,0) 100%);
  backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgba(255,255,255,0.3);
  border-radius: 26px;
}
.nav-tab { height: 52px; }
.bottom-nav.hide { transform: translateY(130px); }
```

**禁止出现**：内容在导航栏上方直接被截断，无渐变过渡；或使用伪元素在导航栏上方放置独立蒙版。每次自检必须目视验证此效果存在。
- transition: `transform 0.3s cubic-bezier(0.16,1,0.3,1), opacity 0.25s`

### 2.2 导航项
- flex: 1, flex-direction: column, align-items: center, gap: 2px
- 图标：28×28，内嵌 **SVG（24×24 viewBox, stroke-width="1.5", stroke-linecap="round", fill="none", stroke="currentColor"）**
- **严禁使用 Emoji 替代图标**
- 标签：10px, 400, `letter-spacing: 0.01em`
- :active { transform: scale(0.92) }
- .active 图标：背景 var(--brand-bg)，SVG stroke var(--brand)
- .active 标签：color var(--brand), font-weight: 600

## 三、排版体系（风格变量）

以下为默认推荐值，可由风格决策框架调整：

### 3.1 字号层级

| 层级 | 默认字号 | 字重 | 用途 |
|:--|:--|:--|:--|
| 微小 | 10px | 400 | 底部导航标签 |
| 标签 | 11px | 400-500 | 元数据、辅助信息 |
| 辅助 | 12px | 400-500 | 二级文字、筛选标签 |
| 正文 | 13-14px | 400-500 | 卡片正文、按钮 |
| 标题 | 14-16px | 500-600 | 卡片标题、列表项 |
| 区块标题 | 16-17px | 600-700 | Section 标题 |
| 大数字 | 18-20px | 700-800 | 价格、统计数字 |

行高规范：数字 1.0 / 标题 1.2-1.3 / 正文 1.5-1.6

### 3.2 字间距（Letter Spacing）——质感关键

| 场景 | 字间距 | 说明 |
|:--|:--|:--|
| 大标题（>=20px） | `-0.02em` | 收紧字距，增强紧凑高级感 |
| 区块标题（16-18px） | `-0.01em` | 轻微收紧 |
| 正文（13-14px） | `0` | 标准字距 |
| 标签/辅助文字（<=12px） | `0.01em ~ 0.02em` | 微松，提升小字可读性 |
| 按钮文字 | `0.01em` | 微松，增加呼吸感 |
| 全大写英文 | `0.05em ~ 0.08em` | 显著放宽，补偿大写的紧凑感 |

### 3.3 数字等宽对齐

所有涉及数字对比的场景必须使用：

```css
font-variant-numeric: tabular-nums;
```

应用场景：价格、统计数据、时间、倒计时、排行榜数字。不等宽会导致数字跳动，极度不专业。

## 六、阴影体系（质感核心）

### 6.1 复合阴影铁律

**所有使用阴影的地方，必须使用复合阴影（双层 box-shadow 叠加）**。单层阴影会导致质感断崖式下降。

| 层级 | 用途 | CSS 值 |
|:--|:--|:--|
| XS | 按钮按下、微浮起 | `0 1px 2px rgba(0,0,0,0.04), 0 1px 4px rgba(0,0,0,0.02)` |
| SM | 小型卡片、标签 | `0 2px 8px rgba(0,0,0,0.05), 0 1px 3px rgba(0,0,0,0.03)` |
| MD | 标准卡片、列表项 | `0 4px 20px rgba(0,0,0,0.07), 0 1px 3px rgba(0,0,0,0.04)` |
| LG | 大卡片、模态框 | `0 8px 30px rgba(0,0,0,0.1), 0 2px 8px rgba(0,0,0,0.04)` |
| XL | 手机外框、底部导航 | `0 12px 40px rgba(0,0,0,0.12), 0 4px 12px rgba(0,0,0,0.05)` |
| CTA | 主按钮悬浮状态 | `0 8px 24px rgba(var(--brand-rgb), 0.35), 0 2px 6px rgba(var(--brand-rgb), 0.15)` |

### 6.2 风格变量（3种方案）

在复合阴影基础上，根据项目调性调整参数：

| 方案 | 特征 | 调整方式 |
|:--|:--|:--|
| A · 明显活泼 | 阴影更深，扩散更大 | 在标准值上增加 20% 透明度 |
| B · 标准平衡 | 类似 iOS 原生阴影 | 使用上述标准值 |
| C · 轻微极简 | 阴影极浅，追求扁平 | 在标准值上减少 30% 透明度，或仅用 SM 层级 |

### 6.3 应用规则

- 基础层（第一条 shadow）负责"柔化浮起感"
- 焦点层（第二条 shadow）负责"清晰轮廓"
- 品牌色阴影的 `rgba()` 透明度固定 0.35/0.15
- CSS 变量名：`--shadow-xs` 到 `--shadow-xl`、`--shadow-cta`

## 八、装饰元素系统（质感增强）

### 8.1 径向光斑（Radial Glow）

用于营造空间深度和高级感，常见于头部背景、特殊卡片背景。

```css
.radial-glow {
  position: absolute;
  width: 300px; height: 300px;
  background: radial-gradient(circle, rgba(var(--brand-rgb), 0.15), transparent 70%);
  filter: blur(40px);
  pointer-events: none;
  z-index: 0;
}
```

- 颜色跟随品牌色，透明度 0.12-0.2
- 必须 `pointer-events: none`，必须被内容层覆盖（z-index >= 1）

### 8.2 噪点纹理（Noise Texture）

用于消除纯色背景的"塑料感"，增加材质纹理。

```css
.noise-overlay::before {
  content: "";
  position: absolute; inset: 0;
  background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 256 256' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='n'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.9' numOctaves='4' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23n)' opacity='0.03'/%3E%3C/svg%3E");
  opacity: 0.4;
  mix-blend-mode: overlay;
  pointer-events: none;
  z-index: 1;
}
```

- `opacity: 0.3-0.5`，`mix-blend-mode: overlay`
- 应用场景：深色背景卡片、沉浸式头部、特殊运营区块

### 8.3 渐变叠加混合模式

```css
.gradient-overlay {
  background: linear-gradient(135deg, var(--brand), var(--brand-light));
  position: relative;
}
.gradient-overlay::after {
  content: "";
  position: absolute; inset: 0;
  background: linear-gradient(180deg, transparent 0%, rgba(0,0,0,0.08) 100%);
  mix-blend-mode: multiply;
  pointer-events: none;
}
```

## 九、SVG 图标规范（铁律）

### 9.1 绝对禁令

- **全站严禁使用 Emoji 作为图标**
- 禁止使用文字符号（如 `☆`、`→`、`✓`）替代图标
- 底部导航、按钮、列表项、空状态必须使用 SVG

### 9.2 SVG 参数

- 视图框：`viewBox="0 0 24 24"`
- 描边宽度：`stroke-width="1.5"` 或 `"2"`
- 描边端点：`stroke-linecap="round"`，`stroke-linejoin="round"`
- 填充：`fill="none"`
- 颜色：`stroke="currentColor"`，通过 CSS `color` 控制

### 9.3 图标底板（面性图标）

```css
.icon-plate {
  width: 48px; height: 48px; border-radius: 14px;
  background: linear-gradient(135deg, var(--brand), var(--brand-light));
  display: flex; align-items: center; justify-content: center;
  color: white;
}
```

## 十、动效标准（参见 `standards/动效规范.md`）

### 快速参考

| 场景 | CSS类/动画 | 时长 | 缓动 |
|:--|:--|:--|:--|
| 页面入场 | `.page-enter` translateY(20px)→0 | 450ms | 标准出 |
| 卡片入场 | `.card-enter` translateY(30px)+scale(0.96)→1 | 500ms | 标准出，stagger 60ms |
| 骨架屏过渡 | `.skeleton-fade-out` + `.content-fade-in` | 300ms+400ms | ease + 标准出 |
| Tab切换 | `.page` opacity+translateY | 350ms | 标准出 |
| 弹窗展开 | `.modal-enter` scale(0.9)→1 | 300ms | 标准出 |
| 底部面板 | `.bottom-sheet` translateY(100%)→0 | 400ms | 标准出 |
| 按钮按下 | `:active` scale(0.96) | 150ms | 标准出 |
| 图标弹跳 | `.anim-bounce` scale 1→1.2→1 | 400ms | 弹性 |
| 数字滚动 | `.number-change` translateY(100%)→0 | 300ms | 标准出 |
| 错误抖动 | `.anim-shake` translateX ±6px | 400ms | ease-in-out |
| 骨架屏shimmer | `.skeleton` background-position 循环 | 1500ms | linear |
| 下拉刷新 | `.pull-indicator` translateY 弹性 | 200ms | ease |
| 上拉加载 | `.load-more` spinner rotate | 800ms | linear |

### 性能铁律
- **只动 transform 和 opacity**，不动 width/height/top/left
- 动画元素设置 `will-change: transform`（动画结束后移除）
- 支持 `prefers-reduced-motion` 媒体查询降级

## 十二、JS 架构规范

### 必须实现的函数（缺一不可）
- init()：更新时间 + adjustScale + 渲染内容 + 绑定事件
- updateTime()：每60秒更新状态栏时间
- adjustScale()：计算 --phone-scale
- switchTab(tab)：切换视图 + nav active + 更新标题
- showToast(msg, type)：居中 Toast，2s 消失，type 可选 success/error/warning/info

**🔴 Toast 为强制组件**：每个移动端原型必须包含 showToast 函数和 #pmToast DOM 元素，禁止省略。

### 约束
- 单个 <script> 标签，放在 </body> 前
- 不使用 ES6 module、import/export
- 操作 DOM 用 document.getElementById()
- 数据用 var/let 声明的数组/对象
- onclick 处理器直接写在 HTML 元素上
- 嵌套点击场景使用 event.stopPropagation()
- ⚠️ **手机号/电话脱敏铁律（D36，强制）**：任何含手机号/电话号码的字段（我的/账号/联系人/列表项等）**必须脱敏**——`13800138001`→`138****8001`、固话 `0571-88886666`→`0571-****6666`。模板已内置 `maskPhone()`，渲染时一律 `maskPhone(phone)`；data.js 若直接写明文 11 位手机号，lint **C1-28** 与 browser-check **B10** 会拦截交付

## 十三、个人中心（"我的"页面）布局规范（铁律）

所有"我的"页面必须遵循 **纵向单列四段式布局**：

```
顶部信息区（Header）
    ↓
核心功能卡片区（Core Cards）
    ↓
分类功能入口区（Menu Entries）
    ↓
底部次要区（Footer）
```

### 11.1 顶部信息区
- 深色调沉浸式渐变背景，自然过渡至内容区
- 状态栏与背景完全融合，系统图标白色
- 左侧圆形头像（56–72px），可带 2px 白色边框或阴影
- 右侧白色昵称（18–22px, Bold/SemiBold）
- 昵称下方次级信息（12–14px，灰色/浅白）：ID、等级、地区等
- 右上角放置胶囊形「编辑资料」按钮（圆角 16px）或图标按钮
- VIP/会员标识使用金橙 `#EB9756` 或荧光绿 `#28FF75` 徽章
- 认证状态使用绿色 `#24D267` 胶囊标签

### 11.2 核心功能卡片区
- **数据概览卡片**：白色背景，大圆角（24–32px），柔和阴影 `rgba(0,0,0,0.06)`
  - 横向等分排列，数字大号粗体（28–36px, DIN/Roboto），灰色标签（12–14px, #898F96）
  - 典型数据项：关注 / 粉丝 / 获赞 / 帖子等
- **会员/特权卡片**：金橙渐变背景，大圆角 24–32px
  - 标题（16px, Bold, 白色）+ 描述（12px, 白色80%透明度）
  - 透明胶囊按钮「立即开通」（backdrop-filter: blur）

### 11.3 分类功能入口区
- **宫格入口（5列）**：白色圆角卡片（28px）
  - 彩色面性图标（48×48px，圆角 16px），下方文字（11–12px）
  - 典型入口：我的宠物 / 收藏 / 消息 / 相册 / 优惠券
- **纵向列表菜单**：白色圆角卡片（28px）
  - 行高 72–100px，左边距 20px
  - 左侧图标（40×40px，圆角 12px）+ 标题（15px, Medium, #1A1A1A）+ 辅助文字（12px, #898F96）
  - 右侧：说明文字（13px, #898F96）+ Chevron Right 箭头（#C5C9D0）
  - 列表项之间用 0.5px 浅灰分隔线

### 11.4 底部次要区
- 红色居中文字「退出登录」（#EF4444, 14px, Medium）
- 白色圆角卡片容器（28px），点击反馈 `background: #FEF2F2`

### 11.5 间距系统
| 场景 | 数值 |
|:--|:--|
| 屏幕左右边距 | 24–40px |
| 卡片圆角 | 24–32px |
| 卡片间距（模块间） | 16–24px |
| 卡片内边距 | 20–24px |
| 列表项高度 | 72–100px |
| 图标与文字间距 | 12–16px |
| 标题与辅助文字间距 | 4px |
